# Dramlo 工作台产品目标与验收基线

更新于 2026-11-25（北京时间）。本文是 Dramlo 的需求、已定方向、交付范围和验收状态的唯一基线。[文档入口](README.md)列出其他文档的用途。后续确认的调整直接更新本文。

## 产品定位

Dramlo 是独立维护、可离线部署的 AI 短剧制作工作台。创作者可以使用熟悉的 MCP Agent 平台和自行选择的模型，通过对话交给 Agent 主导制作，也可以在浏览器里走完整手动流程。两套流程共享项目和画布。生成侧可使用本机 ComfyUI 或自配置的在线图像与视频 API，也面向需要在自有环境部署的团队和企业。

最终完整移除 Dramlo 内置 Agent。外部 Agent 使用自己的会话、模型和供应商，负责理解需求、选用 Skill、创作、审校、看图和规划。Dramlo 负责结构化数据、确定性校验、工作流执行、任务状态和素材落盘。外部 Agent 写回剧本与分镜、最终提示词、素材引用及审校结果时，Dramlo 不应隐式调用自己的文本或视觉供应商。实际图片、视频、音频任务继续使用项目已配置的生成服务。

## 项目初衷

- **让用户沿用熟悉的 Agent 和可负担的用量方案。** 短剧工作台的内置 Agent 常要求另外配置大模型 API。用户已经购买的 Agent 订阅或 Token Plan 未必能用在工作台直连 API 上，可能需要另付按量费用。受套餐兼容、价格与模型支持影响，实际能选的供应商也可能很少。通过 MCP 接入后，用户可以按自己的使用习惯、可用套餐和任务成本选择 Agent。已有 API 额度、赠送额度和本地生成服务也继续可用。
- **把 Agent 入口统一到用户习惯的平台。** 同一个本地 Agent 会话可以读取本机资料、写剧本、查参考，也可以在授权范围内查找和管理 ComfyUI 的工作流与相关素材，再把工作流及成果接入 Dramlo。用户在熟悉的入口完成跨软件任务。项目判断是，Agent 入口会逐步集中到成熟平台，Dramlo 和其他工具可以各自提供清晰的操作接口，由同一个 Agent 协调。能操作的范围以各工具开放的接口和用户授权为准。
- **让外部成果直接进入制作项目。** 例如，当 Codex 客户端及其套餐提供图像生成能力时，用户可以在 Codex 里生成图片，再把产物导入 Dramlo 画布并绑定到素材或镜头。Dramlo 支持接收现有图片，并保留按项目配置使用 API 或 ComfyUI 生成的路径。具体套餐权益和用量按所用平台计算。
- **以接口作为集成边界。** MCP 是面向交互式 Agent 的主要入口，CLI 可覆盖本机脚本和自动化。两者都应复用 Dramlo 已有业务能力，使外部工具与手动画布操作共享项目状态。CLI 是接口方向，交付状态以验收章节为准。
- **按任务提供 MCP 工具说明。** 新接入默认使用精简工具清单，Agent 按当前任务查询所需能力和参数。目标是减少工具定义占用的模型上下文。分层设计与验收见[设计指引](studio-design-guide.md#按任务发现-mcp-工具)。
- **用系统分屏同时看对话和画布。** 用户可以把常用 Agent 客户端和 Dramlo Web 并排，在一侧发指令，在另一侧查看分镜、素材和任务进度，随时手动接手。系统分屏足以承载这种使用方式。Dramlo 应让外部操作的结果在同一项目中及时可见，并让用户方便地把选中的镜头交给 Agent。

### 对 Agent 生态的判断

未来的 Agent 生态可能主要沿两条路线发展。一类是大公司提供的成熟商业 Agent 产品，整合模型、会话、工具和用户套餐。另一类是可供不同应用复用的开源通用底座，可能来自大公司开源，也可能从独立开源项目演进而来。Pi Agent 和 DeepSeek Harness 是用户看好的候选。用户也认为，OpenClaw、Hermes 等独立项目如果缺乏持续差异化，长期空间可能受到挤压。这是对行业演进的判断。

对 Dramlo 而言，MCP 和 CLI 应同时服务这两类 Agent。项目数据和制作状态由 Dramlo 保存，用户可以更换 Agent 而继续原来的制作。接入协议避免依赖某个 Agent 独有的会话格式、模型或账户体系。选定具体客户端时，以工具覆盖和实际验收为准。

## 默认交付形态

- **本机 Web 工作台 + Rust 本地服务。** 沿用 Vue 画布，桌面快捷方式负责启动或复用服务，再打开浏览器。发布包包含本机服务与前端，运行时使用系统浏览器。Vue/Vite 仍可作为开发工具链。Tauri 留作需要原生桌面集成时的候选，不占首版开发范围。
- 本地服务拥有项目写入、配置、ComfyUI 连接、生成队列及任务恢复。界面和 MCP 调用同一业务服务，实时读到变更。关闭浏览器或更换 Agent 后，只要本地服务仍在运行，任务可以继续。重连先读状态。
- 新旧实现切换时验证已有项目、素材和配置。先用隔离项目测读写、视频预览及拖动进度、取尾帧、大文件导入和独立任务，再替换现有启动入口。记录只开服务、打开画布和预览多条视频时的整组进程资源占用。

## 统一 Agent 接入

首次启动显示可关闭的接入引导，并提供「不再显示」。用户可以只把一份包含 MCP 配置、Skill 和工具发现方式的说明交给熟悉的 Agent。后续由 Agent 连接 Dramlo、配置工具、协助选择 ComfyUI 实例和导入工作流。所有 Agent 通过标准工具描述获得一致的输入、输出与确认边界。用户仍在画布查看进度并可手动接手。

| 交付物 | 职责 |
| --- | --- |
| Dramlo MCP | 启动或连接工作台，读写项目、剧本、分镜、画布、素材、设置与模型配置，准备、执行和查询任务，定位原片，保存及退出本地服务。 |
| Dramlo 接入 Skill | 指导外部客户端连通性检查、选择项目、读取最新状态、复用 Dramlo 已有创作 Skill 和插件、取得确认及处理失败。 |
| Dramlo MCP 的 ComfyUI 工具 | 检测指定本机实例并枚举已保存工作流，区分画布格式与 API 图，取得对应 API JSON，核对节点、模型候选、素材输入、参数和输出，支持导入 Dramlo 后读回。 |
| ComfyUI 工作流 Skill | 指导 Agent 选实例、找工作流、获取原生 API 导出，校验角色和场景参考图、首帧与尾帧，并区分导入、检查和实跑。 |

Dramlo 设置内提供「外部 Agent 接入」，显示服务状态、基于实际安装路径的连接信息和连接自检，可复制或下载一份统一接入说明，默认包含 ComfyUI 发现与导入。外部客户端按自身机制注册 MCP。Dramlo 的内置或导入创作 Skill 可被查询并按来源引用，同名 Skill 也可区分。插件由 Dramlo 按原配置和确认流程调用。外部 Agent 保留自己的技能库。

ComfyUI 工作流工具提供原样的 API JSON 及单独的参数绑定说明，可交付其他支持导入 API 图的工作台。工作流源文件、导出版本及其对应依据可追溯。遇到只有画布格式的文件，使用 ComfyUI 原生导出，含子图的工作流也需要核对 API 图。导入成功、配置有效、实际可运行分别验证。目标工作台能否自动导入取决于其接口。

## 制作与人工接手

- 可导入现成剧本，按集和场组织，Agent 可把指定场次拆为分镜草稿，保留原文。每镜记录顺序、时长、动作、对白、提示词、生成方式和角色／场景／道具引用。画布布局独立于拍摄顺序。
- 角色、场景和道具可跨镜复用。支持保存和选用生成或导入的不同版本，并显示引用它的镜头。换参考图只提示相关镜头复核，保留已选成片。界面和 MCP 可读取当前项目、选区、版本、节点连线、有效配置及已保存素材。提交前核对最新内容，发现计划与人工改动冲突时说明差异并重新确认。
- 明确区分只准备与开始生成。可预览将运行的镜头、工作流、素材绑定、缺项和预估调用。一次确认后按分镜顺序逐项提交，结果成功且落盘归档后才继续。失败或结果不明时停止，先核对既有任务 ID 和产物，恢复时跳过已完成项。
- 零产出时可先保存剧本、分镜、提示词、节点、端口绑定和执行顺序。全图读取须核对项目 ID，准备状态须复用实际执行规则，检查生效工作流、镜头输入和素材文件。配置或必填槽问题优先显示为阻塞，其次才显示等待上游。原生 Web 已提供生图、逐镜视频、尾帧提取和基础导出的持久执行计划，界面与 MCP 共用启动、暂停和恢复逻辑。插件及复杂后期按各自入口执行。
- 普通切镜可直接使用角色或场景参考。连续动作可用上一镜已选成片的真实尾帧作首帧。换场或硬切可断开。只显示和提交工作流所支持的输入，首帧与普通参考图分别绑定。前镜换片后只提示复核其下游依赖。
- 视频自动归到对应镜头及项目素材库。按集、场、镜头定位候选，预览和选用版本，查看生成来源，打开所在文件夹或复制原片路径。文件缺失明确反馈。重开项目后可查分镜、候选、选用结果和未完成任务。

## 项目灵感库（待实现）

每个项目有独立的灵感库，用于保存创作笔记、图片、视频和音频参考。条目归属一个项目，可附标题、备注和来源，支持预览。灵感条目独立于正式制作素材。用户需要用于生成时，可以明确选入项目素材库，再绑定到镜头。

- 首页的「灵感库」按项目列出各库。项目内提供直达当前灵感库的入口，也可切换查看其他项目的库。浏览其他库时保持当前编辑项目，写入前明确目标项目。
- 用户和 Agent 共用同一份记录。MCP 支持按项目列出、搜索和读取条目，新增文本、追加或修订笔记，以及把用户提供的本地媒体收录到指定项目。保存后返回条目位置，用户可在 Dramlo 里打开。日常记录沿用创作阶段的操作方式，无需逐条确认。
- 验收用两个项目。用户边聊边让 Agent 记下一条灵感并补充内容，再收录图片、视频和音频。分别从项目入口、首页和另一项目打开同一批条目，确认媒体能预览，浏览时当前项目不变。只将明确选中的参考转入目标项目的素材库。

## 配置和应用管理

- 首次打开优先检测已有 ComfyUI 与保存位置，允许手动指定，探测和预览先于写入。在一处管理本地或在线生成供应商、模型、默认画幅、目录、工作流与绑定。设置页能查看不可用项和原因，生成菜单默认提供通过相应检查的选项。
- 显示全局默认、项目覆盖、镜头覆盖和实际生效值。改全局默认保留已有显式覆盖。通过界面和 MCP 双向读回并显示保存结果。区分只读检查、连接探测和实际生成试跑。密钥由用户录入或更换，Agent 读取配置状态。
- 支持启动、复用实例、打开指定项目、保存退出。重启前核对活动任务及影响，回来恢复原项目。暂停后续镜头默认等待当前镜头完成，停止当前生成单独处理。保存退出时先保存已收素材并说明任务去向。Dramlo 退出与共享 ComfyUI 停止分开处理。
- 用户可随时在界面接手。删除素材、覆盖项目和停止共享 ComfyUI 等动作单独确认。外部 Agent 不可用时，手动启动、设置和制作照常可用。
- [操作手册](studio-operation-manual.md)从配置覆盖到画布和产物。每项功能记录手动入口、MCP 入口、预期结果和人工接手方式。手册、统一接入说明、指导 Skill 及工具合同随版本同步更新。

项目读写使用当前数据格式。旧项目的原始素材和项目文件可单独打包留存，重建项目时按需导入素材。

## 交付顺序与验收

1. **先跑一镜。** 外部 Agent 启动或连接 Dramlo，打开隔离项目，选用 Dramlo 已有的自定义分镜 Skill 拆一场戏，把结构化成果写回。读取用户手动改过的提示词或参考。在本机查到 H3 高配尾帧工作流，取得 API 图、导入并读回映射，再通过现有视频插件跑一镜。原片回到原项目和镜头，可预览、选用并定位本地文件。以未在 Dramlo 配置文本／视觉供应商的条件验收全链路。
2. **再验收配置和 Web 交付。** 验证双击启动、复用实例、首次发现、配置重开、界面与 MCP 双向读写、项目覆盖和实际生效配置。用带子图的 H3 Image 检查导出关联。关闭页面后任务可继续，重开能看到结果。验证保存退出对共享 ComfyUI 无影响。
3. **最后补齐两场三镜和移除旧运行时。** 前两镜连续，第三镜换场。一次确认后按顺序执行，第二镜用第一镜已选成片的真实尾帧，第三镜不用前场尾帧。模拟失败、暂停、关闭页面和服务重开，确认状态与产物可恢复、未完成项可继续。删除内置聊天及其推理、会话编排和专用依赖。技术盘点和待迁接口见[迁移清单](studio-agent-migration.md)。

首版验收到**逐镜生成、预览、选片和定位原片**。整集剪辑、配乐、加字幕和导出保留为已有能力或后续范围。

后续按「用户和 Agent 共用同一项目」补齐操作入口。优先验收整批重切分镜（逐镜场次、顺序和已选素材的处理）、按配置 ID 读取可执行性和缺项，以及派生画布同步。Agent 应能通过工具或操作手册判断实际提示词、节点派生规则和供应商支持范围。生成授权继续以整批计划为单位。原生 Web 的时间线编辑和导出另行验收。
