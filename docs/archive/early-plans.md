# 早期方案归档

本页归档最初的独立适配层和外部 Agent 接入方案。交付方向与验收以[产品基线](../studio-product-goal.md)为准，现有操作见[手册](../studio-operation-manual.md)。

## 决策沿革

1. 曾计划在原版剧流之外提供独立适配层和指导 Skill，仅调用原版已验证的入口。这条方案保留了「外部 Agent 可自由选择、复用已有 H3、先验证一镜、产物归原项目」的要求。
2. 用户要求调整 UI、工作流操作并按需纳入上游修改，决定使用独立 GitHub Fork。原版项目恢复到上游版本，已有改动迁入 Fork。
3. 曾保留内置聊天作为可选入口，后来决定完整移除内置运行时、全面 MCP 化。默认交付形态已定为 Vue 本机 Web 工作台与 Rust 本地服务。
4. 早期 MCP 计划包含时间线和成片导出，已完成隔离 MP4 测试。当前短剧首版验收到镜头原片，整集剪辑和导出不作为验收门槛。
