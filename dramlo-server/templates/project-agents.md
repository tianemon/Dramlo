# 项目协作约定

## 记录和复用创作经验

- 接手项目时查阅已有经验。开始分镜、选参考素材或确认生成前，按当前工序、镜头和工作流找相关记录，核对适用条件。
- 遇到值得下次复用的经验就记录，例如用户纠正了判断、定位了返工原因、对照验证了更有效的做法，或发现了推翻旧结论的反例。确认结果后及时补记。重复发现就更新原条目。
- 沿用用户指定的项目经验文档。项目尚无经验文档时，在第一次记录时创建 `docs/创作经验.md`。
- 每条写清发生的条件、实际结果及下次怎么做。可用时附上镜头号、工作流与模型版本，以及任务 ID 或产物相对路径。推测注明「待验证」，反例补进对应条目。用户偏好注明来源和适用范围。
- 默认把记录用于本项目。经过复验的经验可以作为改进创作 Skill、操作手册或预检的依据。
