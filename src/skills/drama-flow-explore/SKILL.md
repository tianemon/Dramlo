# 从小说改编到单集成片

全剧改编时，用[故事与分集](references/story.md)排全剧集序，标出每次揭晓由哪场建立、后面哪场要用，用[分场与对白](references/screenplay.md)形成分集剧本。制作完整一集时指定集号，读取该集定稿、共用资产与相关前集的实际结尾。只处理一场或一个镜头时，用场号或镜号标范围，采用用户确定的剧本段落或本轮描述；仅在结果依赖前后内容时补读。只有点子时先补简短梗概；已有分场剧本可直接排戏；已有粗剪先定位具体片段。按手头的创作决定选读。接手一个阶段时，从对应手册取执行方法、工作单和验收，执行时优先读对应步骤旁的判断和证据，再按该条引用定位原文行段。执行原方案的数字、例外、模板和输入模式时，连同原文限制一起使用。

| 当前任务 | 手册与交付 |
|---|---|
| 1 确认本集任务 | 从全剧分集剧本定位目标集，用[连续性](references/continuity.md)核对前集实际呈现和前后集已采用的段落，确定本集要承接的条件、要兑现的变化及可改范围。 |
| 2 核对本集剧本或按委托修订 | 用[分场与对白](references/screenplay.md)写定台词、动作和场尾结果；对白重叠、旁白或画外线索影响叙事时同步读[声音](references/sound.md)。 |
| 3 设计场面与切镜 | 先用[导演设计](references/director.md)排视点、表演与走位，再用[分镜脚本](references/storyboard.md)定画面、节拍、声音与剪点。遇到关键接触、复杂走位、口型或精确续接时，用[关键镜组](references/storyboard.md#shot-group-decisions)比较可行拍法。有后配对白时，先依[对白与口型](references/sound.md)决定拍说者还是听者。空间或接续难以判断时才画[看板](references/panel.md)。 |
| 4 提取、制作和选用资产 | 全新项目先用[资产](references/assets.md)比较视觉方案，定首套参考；已有项目从剧本初提人物、道具与状态，再从镜表补逐镜用途。复用场地、多机位或反拍时读[场景](references/scene.md)。 |
| 5 决定这一镜怎样生成 | 用[逐镜输入与终稿](references/final-prompt.md)分清身份参考、动作看板与精确端点，依据本镜接点和可用输入选择控制方式，交付自足的正文、输入及剪辑同步。交稿前用[委托逐项核对](references/final-prompt.md#delivery-check)反查必发生动作、原话、揭示时点与最终状态。需要定一个瞬间时读[静帧](references/keyframe.md)，要表现变化时读[动态镜头](references/video.md)。 |
| 6 取得片段并选用 | 用[选片与审读](references/review.md)连看候选与前后镜，核对实际动作相位、声音和可剪区间；需要先试一个镜组时读[试片与制作](references/production.md)。 |
| 7 完成一集 | 用[剪辑与交付](references/edit.md)组粗剪、修节奏、安排字幕，用[声音](references/sound.md)落实原声或配音、音效和音乐。验收本集成片，将实际结尾、人物状态和采用素材交给相关后集。 |

改编、跨镜或换版涉及事实变化时查[连续性](references/continuity.md)。素材未齐时可先写镜表和参考来源；有实际媒体后再判断表演和接续。平台操作与模型语法跟随使用环境，创作稿保留作者采用的事实与视听意图。

## 按当次制作问题选读

关键镜组在进入生成稿前交清「必须交付的证据｜采用拍法｜必要输入｜剪点与回退」。涉及关键信息反复交代、反应来不及读或集末落点不清时，用[首次观看检查](references/storyboard.md#first-view)。需要看完整交接时，读[两种覆盖的交接戏](references/example-handover.md)或[动作完成后仍需说出的承诺](references/example-offscreen-promise.md)。示范用于比较拍法，不把案例的画幅、时长或表演当项目默认。

## 使用原文资料

每个专题手册说明本套通用流程怎么用，相应原文分卷保留资料库提供的完整文件。从每条规则点到原文，或从[来源与覆盖记录](references/source-index.md)反查原文影响了哪些规则。引用标注的是原文件行号。MCP 读取引用时，传文件路径，正文内用资料序号与原文行号定位。原文中的模型格式、套件默认值、联网、脚本及审批步骤属于来源语境。采用要求由用户定稿、任务范围和实际执行环境决定。正文可先读取相应手册及需要的分卷，再产出当前工序要求的实际交付物。
