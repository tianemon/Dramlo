````markdown
# 视频提示词与挂图计划

输入定稿剧本相关行、镜头表、视觉参考及目标模型的已知能力。保持镜号、起止状态、信息揭露和台词。先判定输入方式，随后按目标接口实际支持的槽位交付。图生视频写清首帧之后发生的事，纯文本输入补齐首个可见画面。

按动作先后分解触发、动作、接触、结果与余势。一个镜头只要求模型完成物理上相容的运动。双手托盘时不能同手开门。主体走位、机位移动和焦点变化分别有起止依据。留出观众辨认物件的时间。对白按实际发声语言估算，画外声可与画面并行，声音跨剪点时只算一次。把提示词与制作备注分别给出。

逐镜决定是否需要身份或地点参考、起幅、目标末帧。反打可复用身份图，同构动作接续可取前镜实际保留端点，只有终点须锁定也可单给末帧。组合方式以输入槽支持为准。见[挂图计划与失败修复](references/挂图计划.md)。

按镜交一份模型可读的正向动作描述，附原语言对白、声源和环境音。整集连续配乐移交剪辑。平台若限制单段时长，优先在可交接的动作端点分段，计算起止位置；发现对白念不完，回查分镜容量或交编剧裁剪。局部失败时只改承担失败的参考、动作或参数，记录用过的版本与仍可用的片段。

同场相邻镜要合生时，另列组号、成员镜号与版次、各镜在组内的起止、切换提示、组总长和组级输入图。逐镜重新检查可见范围，特别是第二镜才入场的人物。一个成品文件可以按区间回指多个镜号。若要求固定台词和口型，标明引擎音画同出还是按定稿配音驱动；后配模式预留发声窗与可剪气口，另交对白干声。

多人对白先把角色 ID、参考图槽和声源对上，再排发声顺序。例如图一是听者、图二是门外先开口的人，镜头留在听者脸上，声音来自门后。听者听见自己的名字时可以转头，嘴形仍与沉默相符。下一镜换发言人也沿用原绑定。对白框只填定稿原话，屏幕文字另记出现位置和时点。选用剧流 H3 工作流时再读[输入模式与声音](references/剧流H3.md)。
````

## 2. 两种挂图决策

资料库路径 `SKILL/studio-motion/references/挂图计划.md`。范围为原文件第 1–10 行。

````markdown
# 两种挂图决策

| 场面与镜 | 意图、起止 | 图片职责 | 交接与修复 |
| --- | --- | --- | --- |
| 对话 D1 | 双人同框，听者还不知道时间差，末尾说出数字 | 复用两人的定妆和同一地点，普通站位用文字安排 | 为后续留下两人视线方向；末帧只需记录状态 |
| 对话 D2 | 切听者近景，数字落下后才起反应 | 同一身份图；反打需要新的观察位置，依实拍或生成能力再决定是否定首帧 | 沿用 D1 的视线和声场。若眼线不连，先修机位和对方的画外位置 |
| 动作 A1 | 舱盖从开到合，最后锁舌落位 | 角色和舱门结构图；锁舌位置须精确可辨时锁定本镜目标末帧 | 复看实际成片，从稳定的合拢状态取可保留的末帧 |
| 动作 A2 | 同构图接锁舌的余振，随后松手 | 实际 A1 保留末帧作为 A2 首帧，已闭是初始条件 | 检查门仍闭、手指尚未提前撤离。末帧无新的精确构图需求，可自由结束 |

参考计划还没得到图片时，写清将在哪个环节取得及缺图影响。引用合成输出作下一镜输入时，要能凭路径、镜版和帧号找到。若首帧与角色设定冲突，先修源图或舍弃错误维度，避免把冲突交给模型自由选择。指定双端约束前检查两端能否在允许的时长与相机路径内相连。
````

## 3. 生成入口、动作与返修

资料库路径 `SKILL/laotang-cinematic-storyboard-s10-free__老唐创作套件/references/readiness.md`。范围为原文件第 1–48 行。

````markdown
# 生成入口、动作与返修

<a id="r00"></a>
## R00 加载分支

所有新建完整稿/单镜独立稿、入口切换或明确就绪审校读R01、R02、R04。续拍/局部编辑/连接段另读R01的操作范围；有承重、抓握、交接、碰撞、跌倒、开火或复杂多阶段动作，连同新建预览的内部动作规划，都必须读R03。生成结果（视频）诊断返修属于至臻完美版能力，本版只按用户描述改对应镜头提示词；普通文本预览、润色、忠实提取可不读入口/媒体部分。

本文件不调用模型，不代替剧情、摄影或统一验收。入口参数证据与T/D/L/U/V等双时钟由路由唯一管理；字段由输出模板管理，不在此复制大模板。

<a id="r01"></a>
## R01 入口证据与操作范围

完整编译前明确产品/模型/版本、模式（文生/图生/参考/首尾帧/编辑/续写）、画幅、时间控制方式、引用机制及实际终点。复用未变化的核实记录；未知标待核实，示例秒数/他产品/常见规格不作当前事实。目标入口不支持的时间码、镜数、绑定机制不能靠文字假设存在。

连续多镜输入明确真实镜序边界，独立输入各自足且时间归零，完整版块外留全局位置。换入口保锁定故事、状态、镜头职责，再改参数语法与引用，不把接口语法当电影通则。输入就绪不等于画面/人物/声音实测通过；素材三项状态及稿件类别读[assets AS01](assets.md#as01)。

先区分新拍、补前/后续、改既有区间或只桥接；已明确顺序/终点直接沿用，仅影响结果的歧义补缺。

- 续段明确前还是后、长度和采用的源片保留端点；不重演源片内容。用实际保留边界而非文件物理首尾/未采用计划帧，没素材不称尾帧已绑定，文字可先完成。
- 连续接点除姿态/位置，核方向、速度变化趋势、动作相位、相机运动阶段和发声结束与否，单张截图不能证明。换机位/跳时按真实关系重新起镜；跨生成大段按故事S7选择有动机切换或同构接续，不把所有接点强成同构，也不一律要求换画面。
- 局部编辑定位对象、区间、区域、属性/动作与保持项；阴影/反光/遮挡/受力可合理联动。只桥接保护两段源片，写清入出状态方向，不默认全片重做。

<a id="r02"></a>
## R02 单镜执行要素

完整模板中依实际需要齐备：主体及资产职责；可见起幅/持物/接触/空间；触发—方向—关键接触/转换—结果；景别/裁切/机位/构图与主运动；真实声音/风格；切出状态。它们是同一份输入的骨架，不要再输出一套六项分析表。

瞬间动作至少有起因与结果，多阶段事件写必须先后的关节，不给常规过程逐动作派秒。机位与主体运动分开，不让“追着主体”承担相反指令。必要光源/遮挡沿空间和摄影规则，声音归属/时点沿[audio](audio.md)，表演沿[acting](acting.md)。可压重复形容词，不能压资产绑定、因果、关键状态、原话和必须可读的关系。

<a id="r03"></a>
## R03 接触物理与复杂动作

每个连续拍摄单元有一个主动作目标，可带相容辅助反应；互不相关主动作、相机运动、转场/声音变化竞争时先判覆盖与复杂度，不以堆词提高复杂度。节拍、姿态格、镜内阶段不等于摄影镜头，只有观察对象/空间判断/揭示时机确实需要才切。

按起始条件→触发→关键接触/操作→结果→切出状态检查链；可并行真并行，依赖前项则先后。涉及推拉、重量、支撑、抓握、承托、递交、碰撞、受击、跌倒、开火/改向时，写发起/受动者、触点、发力/受力方向、支撑/重心、位移和结束/打断方式。维持抓握/承托与活动关节/双腿分开，不冻结步态导致滑行，不让受动者无故主动配合；触点、重量、距离相容，尺度服从已确认写实/动画。并非每次都展开预备/执行/余势，仅必要原因/接触/结果分别呈现。主体是动物、机器人或拟人物品时，按实际肢体/机构数量、支撑点、可动范围和材质检查；四足、飞行、轮行不套人类脚步和双手规则，刚体不为表演软化，柔体不无限变形，骑者与坐骑分别跟踪状态和受力。

动作起中末图、A/B子格、箭头先辨真实镜号与切点；分别解释主体运动、相机运动和取景，不自动各占镜或秒。连招能同输入可读就统一承载，拆输入写阶段兼容，不反复复位、不靠切镜虚减时长。状态节点不能省掉唯一交接、计数、揭示或结果；普通移动可省/中途切，必须因果可懂。

反复失败先查参考状态、路径/机位、动作负担或入口能力；可选构图图/关键姿态/已授权预演辅助，不默认启动3D，不把预演可控当模型保证。首尾帧/参考视频只有用户选且入口支持才为生成控制，文字“延续”不证明绑定。

<a id="r04"></a>
## R04 冲突处理

排查顺序：锁定事实/拍法/原话/知情边界→人物道具空间连续→必要动作及真实依赖→必须同时读到的证据→主相机运动→风格修饰。此顺序只是定位，不授权删任何用户硬要求，无法兼得按路由的时长/权限冲突处理。

固定与跟拍、全程背面与必须正脸、小特写与多人交接、遮挡证据与立即识别、慢动作与真实声画节奏、多位置跳转塞短区间等不能并存。先找不可替代证据，再在授权范围改取景/覆盖或报告真实硬冲突，不为了满足清单盲加镜。

与其他专题同用质量检查一轮；媒体验证只报告实际检查的范围及未测项。
````

## 4. 视频提示词

资料库路径 `原创/short-drama-video-prompts/SKILL.md`。范围为原文件第 1–13 行。

````markdown
---
name: short-drama-video-prompts
description: "将短剧镜头卡转成可提交的视频提示词，用于 MiniMax H3 在 ComfyUI 中的文生、首帧、尾帧、首尾帧、多参考视频，以及对白、音效和延续。"
---

# 视频提示词

1. 先核对实际绑定的工作流、输入槽和模式；提示词不能代替连线。详见 [H3 模式与模板](references/h3-modes.md)。别根据工作流文件名猜模式；沿实际活动路径确认 frame/reference 输入和输出时长。
2. 镜内只设置一个主要变化，写清开场已有状态、何时开始、如何发展、如何停下和反应。时间放在动作确有意义的区间，不死凑秒段。不用抽象心理代替动作，不复述人物看不见的背景故事。单镜头说清不切，另写摄影机的起点/路径/速度/终点；机位不动也要说清。
3. 从可读取的实际首帧或已通过的上镜尾帧提取空间与动作事实。跨镜状态已发生就只写后果或新动作，避免模型误读为再次发生。没看到画面时不得宣称“已核对末帧”。
4. 对白保留剧本原句、语言、说话人/对象和说话点，声明是否有旁白、哪些人不说话。台词读不完就先建议拆镜或确认调整，不能私自删改。对白、环境、动作声、配乐分开；跨镜音乐一般用后期同一条轨，不要求每段生成都接续同一段 BGM。
5. 只保留跟当前动作有关的身份与空间锚点。尾帧为硬输入时确保两端匹配画幅、光线、对象数、道具归属与可实现动作路径。预期画幅/时长/帧率写进节点参数，提示词里的秒数与实际工作流参数一致。
6. 输出可直接提交的 prompt、调用参数、参考绑定表与验收点。未知格式或陌生模型保留模型无关镜头稿，待确认后才渲染模板；不要同时塞入多种格式或在没有可信配置时猜测提示词长度上限。
````
