# 来源与覆盖记录

## 核对范围

本次整合以桌面「短剧创作资料库」中与既有十五份手册直接对应的创作专业材料为范围，保留此前采用的通用流程与审稿规则。原文分卷中列出实际收录的全文件。作者、版本、更新时间以各原件标题、元数据或署名为准；缺项未推定。此处的证据是已提供手册文本，手册提及的论文、产品限制和研究结果未逐一到第三方原始页面复验。套件提供的经验、规范和样例依原适用条件使用。

**收录范围之外**：同源的 Toonflow 镜像、单文件合订本、剧流/Toonflow/ComfyUI 工具教程、H3 专用语法、平台特效及美术档位全集、小说写作专用资料、广告和 MV 预设、项目独有内容、事故日志及媒体验证都沿资料库原目录留存。完整原文对照的承诺只针对下列已收录文件。有关 H3、联网或脚本的词句若位于收录原文内，按原来源保存，作为适用边界记录。

## 版本差异与适用边界

- **人物板。** 四视图、完整三列和无头左列均有不同观看任务。三列模式的对位、领口边界和内容限制仍适用于选择该模式的读者。制作单幅首帧按目标入口，另验实际姿态和构图。
- **反拍。** 可按故事和现有资料先交几何预案。要求正式依首图的场景流程以实际采用图为证，保留原文中的首图、回看、反拍顺序。画外布局只有来源可作依据。
- **表演。** 导演助理特定真人档包含多拍、面部约束和经验症状。另有通用表演方法按景别、刺激、相容部位和叙事节奏选择；拍数、FACS 写法及效果描述未升为平台通用规则。
- **节奏。** 自然估时、锁定时长、平台素材上限和成片播放区间分别核。原本给出的快速预估表、参考比例、反注水阈值、分段上限和单段例题仍在分卷，作为原方案的参数。
- **声音与导出。** 保留对白与口型的可见条件、不同声源时间、字幕和响度验证逻辑；目标平台指定数值只在该交付适用。
- **审读。** 原文中的定制门槛、脚本执行、模型字段与单案结果均可定位到原文件。手册的执行规则按当前用户任务和实际约束落地。

## 规则的采纳理由与限制

手册中的「采用」表示来源给出了该做法。「综合」表示把不同来源或已确认的技能要求连成一个决策，核对办法属于编辑层时按其用途使用。「限定采用」保留某个模板、输入或作品条件下的原有要求。原文没有给出固定阈值时，以具体作品的证据、计时或看片决定。

| 容易混用的主张 | 本版决定与理由 |
| --- | --- |
| 真人近景必须用固定拍数、面部分区和特定微动作限制 | 保留专业档的原有约束与动作库。该约束明确隶属于特定风格模块，通用表演只选在画框中读得出、且与动作和发声相容的变化。见[近景专项](director.md#rule-director-03)。 |
| 紧凑、标准、舒缓套固定数字，或者硬把每镜填到整数秒 | 原值和单位留在原文。可选三档作为初估，按同词句与语言实读，以事件轴计算素材及净长。动作主导无需算对白倍率，固定总长不能被档位改写。见[自然占用](storyboard.md#rule-storyboard-03)与[三档粗估](storyboard.md#rule-storyboard-06)。 |
| 只有重复出场才建资产，或者所有提及对象都做图 | 单次关键证据也可能需要素材。仅被提及的对象先登记，剧情未来有独立辨识要求再定锚点和制作时机。见[两轮提取](assets.md#rule-assets-01)。 |
| 角色板一律四视图或一律三列，或把两种三列头部约束混写 | 引用的展示方案各随观看任务使用。三列的身体对齐、领口高低及专用负面段按实际选定模式。侧面需求可另补单幅。见[人物板](assets.md#rule-assets-04)。 |
| 同一场景反拍只要水平镜像，或一律用特定焦距、视高 | 原文给了可靠的共轴条件和模板参数，实际布置不同时重算空间投影，未知尺寸不当作实测。见[两端机位](scene.md#rule-scene-04)。 |
| 所有镜段都加一秒静止，或者全剪便不占素材容量 | 专项锚点取决于后续独立段是否需要；启用时原稿的一秒是有效生成区间而非每个完整素材的固定长。成片与素材分别复算。见[静止锚点](panel.md#rule-panel-03)。 |
| 按套件默认关闭所有音乐或字幕，或把某平台字幕参数推广 | 将模板默认、实拍设计选择和交付要求分开。戏内与戏外、声音与硬字幕分别处理，真实交付规格按委托核证。见[跨切与音乐](sound.md#rule-sound-04)与[字幕](edit.md#rule-edit-02)。 |
| 参考资料中的入口字段、校验器、命令和生成效果可直接继承 | 保留在来源语境。能力以当前入口及实际输入为准，结构校验和媒体验收分别记。见[选输入](video.md#rule-video-01)与[提交与恢复](production.md#rule-production-02)。 |
