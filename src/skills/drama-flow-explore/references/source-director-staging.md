````markdown
# 导演方案

把场次写到演员知道此刻对谁做什么，摄影知道要看清哪一刻，录音和剪辑知道哪条声音或动作要接上。用户只问一项拍法时，直接解这一项。用户要逐镜时码、分镜表或模型输入时，将已确定的导演选择交给分镜环节。导演方案本身可独立使用。

## 从原稿到拍法

1. 取本轮指定版本，标出原话、事件结果、人物与观众所知、不可提前暴露的信息，以及指定的长镜、画幅、时长、既有素材。原稿留下的沉默、误认、省略也属于叙事。给已有故事选取景和排练动作时保留这些事实。用户授权新编时，可补写授权范围内的内容，标清会改变后文的选择。
2. 找到本场观众需要看懂的变化，以及变化发生之前应当相信什么。选择谁带观众进入，谁的反应值得留下，哪项证据可以给观众先看。若场景旨在等待或相处，一段持续动作也可承担整场。用一句可核对的观看结果写下意图。
3. 把意图变成人、机位和声音的安排。先按地标站位试演，再选同框、单人、过肩、主观或局部。每项选择说明它保住了什么信息、把什么留在画外。普通场面给一个可执行解。用户要比较，或两种拍法确会改变悬念与同情对象时，给出各自的代价和推荐。
4. 从切出状态交接到下一场，注明需要延续的动作、光源或声音，以及明确经过的故事时间。改既有方案仅动指定部分和依赖它的接点。在准备稿上发现两项锁定要求无法同时拍清，指出冲突发生在哪个瞬间及可替换的具体拍法。

## 调用资料

- 排戏、摄影、声场或节奏有实际选择时，读[场面调度与声画](references/scene-direction.md)相应小节。
- 诊断一场戏为何失效或需要试排时，用[排练与复查](references/rehearsal.md)定位可观察的失败点。
- 交全场方案可套用[导演工作页](references/assets/scene-plan.md)，只保留对当前协作人员有用的栏目。沿用剧组或作者已有表式。

用户要把剧本转成可直接阅读的导演画面版或声画版时，保留原场头、顺序、人物和定稿台词，把必要的站位、动作及叙事声音写进相应动作段。标明源稿版本和改编范围，另交派生稿。只有交给制作方且对方需要时才附技术参数。源稿若后来改了台词、出场次序或揭示位置，回查引用该处的场次及其接点。

交前按原稿顺序过一遍。即便静音，关键选择也应有足够的画面证据，原稿有意让声音独自揭示的除外。再闭眼检查重要台词、环境变化和揭示声能否辨认。没有片段时，这两遍均是书面推演。
````

## 2. 场面调度与声画

````markdown
# 场面调度与声画

## 观众站在谁一边

把一句抽象主题换成可检验的入场和离场状态。例如“观众起初以为她催人开门，到结尾才明白她在替屋里的人挡住来客”。依原稿确认最早允许看清、听清或猜到哪一点。拍门外人的主观视点，会暂时失去门内人脸上的变化。若镜头先给屋内的选择，门外人的追问就成为观众已知答案的压力。两种剪法改变的是信息次序。

遇到内心叙述，找原稿已有的选择或操作承担它。已有一件工作做到一半，演员继续、暂缓或因新信息改变力度，都比单独另加一个“说明心情”的动作省事。内心活动只有在原稿或改编授权采用独白时才能成为声音。不能为方便解释让旁人也听到。

同一条线索应区分“第一次能察觉”和“第一次能认出”。原稿安排帘后的人最后才露脸，可以先让观众听见原有的一声轻咳，同时留住身份。若原稿连有人在场都要保密，提前加影子或脚步同样会泄底。已露面的普通物件后来成为证据时，第一次留到什么程度、何时给它足够清晰的细节，由原稿的回收位置决定。

## 给演员的指令

用对手能接受或拒绝的具体动作布置任务，例如“问完继续等她自己把单据翻过来”。按当刻人物实际看见、听见的事件安排改变。台词揭底发生在最后一个短语时，听者在此前仍按原理解行动。信息在半句已经足够时，反应可以压在话尾。定稿的原词、笑声、被打断的半句照录。

排练时分清身体朝向、头脸、目光和双手占用。人物双手端着托盘，受惊后可以重新稳住重心。如果只露背影，就让停步和托盘的倾角承担信息。不给背面演员布置观众看不见的嘴角戏。演员平静地看住门框，直到对方答复，也能维持场面。群戏逐人核是否听得到、看得到。共同听见一声脆响可以同时回头，隔门戴着耳机的人要有自己的依据。

自然动物按其感官、支撑和活动范围响应。拟人物件用它已有的关节、灯头、轮子或声源。无嘴的机器人可用既定扬声器说话。背景睡猫不需要人为安排策略，不能为了“表演丰富”让它知道角色的秘密。

## 站位、机位、光和覆盖

先挑观众能辨的一两个地标，用它们固定人物和主光的世界位置，再随机位推导画幅左右、前后、视线和可见背景。两人位置未动，摄影机从并肩者背后移到正面，两人会交换屏幕左右。需要换轴可以让观众看见穿越，或用有地标的同框重新定向。三人转而与第三人交谈时，新的互动轴可能不再是原来那条。画外的人仍可在场。

画幅直接影响证据。竖构图容不下横排三人时，有走位自由可以利用纵深，已经锁定并肩站位则改取景或选一段信息明确的覆盖。交接、触点、手的归属和对手反应若必须同时看到，先试能装下它们的中景。取特写时问清本镜确要辨识的物件属于谁、此时谁能看见。现场主光绑在窗或灯的位置，反打时面部亮侧投影可以改变。

摄影指令分别说清主体路径和机位路径。固定镜中人物向观众逼近，影像会逐渐占满画面。站在原地变焦能收窄取景。前移机位还会改变前后景相对关系。关键细节被遮住时先改落点、裁切或焦点，再决定是否加镜。长镜可靠人走入同一构图或注意转移推进。切点以新的观看需要为准。

## 声音、媒介与剪辑

分别找出说话者、声源所在空间和当下承担观察任务的人。拍听者时，画外说者继续说原话。旁白或内心声音期间，画内人照常做自己的事。隔墙回放需区分原发声、播放设备和听者所在房间。稳定声音身份与这一句压低、迟疑或抢话的读法分开记。环境底声跨反打延续，距离、遮挡或门的开合才改变听感。

让关键拟音与接触时点相合。若声音先把观众带到下一处，可在当前画面尾部进入下一场的声音。若一句未完而已切给听者，划清何处续完。只有新声音到达才发生的转头，不得提早。现场音乐、人物能否听见、后期配乐分开安排，剧情约定的安静也要留下。

视觉方向用可见材料、光线和运动体现。实拍的纸折产生压痕，定格动画可以按已有材质分段改变轮廓。一张概念参考分别可能只负责色彩、材质、构图或角色外形，不应顺势继承其背景人物或姿态。使用实物、动画和生成素材时，都保留同一个转折和表演职责。只有制作方式和可行的控制手段发生改变。

技术效果本身传递信息时，写清从哪里开始能被看见或听见、如何经过已有空间、谁最先感知、结束后留下什么。例如原稿写隔音屏的三格指示灯逐格熄灭，最后一格暗下去时屋里人才听清走廊的谈话。前两格可以让门外的人影入画，但屋里人的回应必须等那句原话传进来。若原稿只说听见含混人声，就保留这层含混。监控、回放或主观段使用与现场不同的画幅或声场时，标清起止和回到现场的接点。
````

## 3. 排练与复查

````markdown
# 排练与复查

从已观察到的具体问题开始。可读的素材先定位时码、镜号或原句，只有文字便指明文字位置。单帧可以看遮挡，运动方向与速度要比较邻帧，台词是否清楚须听实际声轨。

| 症状 | 先查的证据 | 最小修订 |
| --- | --- | --- |
| 人物像预先知道答案 | 台词里哪一截才足以明白，对方能否听清 | 保留此前的既有任务，在信息到达后改变一项可见行为 |
| 交接看似发生了两遍 | 前后镜各自切在哪个接触阶段 | 一镜止于对方接稳，下一镜从原持有人松手之后继续 |
| 人物一切反打便换了位置 | 地标、行动轴、镜头在轴线哪侧、人物是否真移动 | 从新机位重画屏幕投影，必要时交代跨轴过程或地标 |
| 场面虽热闹，关键证据始终看不清 | 证据出现时的大小、前景遮挡、焦点、停留和竞争动作 | 改同镜调度或注意中心，确实无法兼见才补覆盖 |
| 同一段越导越长 | 走位和说话实际是否能同步，哪一拍非先做完不可 | 合并重叠占用，保住接触、句末反应和指定等待 |
| 观众分不清谁在说话 | 画外声、现场声、设备重放、声源揭示时机 | 写清听觉方位与归属，把口型留给可见发声者 |

## 一次排演示例

**原稿**　两名修复员在纸本工作台两侧。许说“背页有字”，钟把夹在玻璃下的纸翻过来。许把灯稍微压低，两人这才看见一个淡得几乎辨不出的年份。两人都没有念出来。

**观看选择**　先保持能同时看见两个人的手、玻璃与灯头的斜侧双人中景，给许的那句话留在现场。钟先移开玻璃再翻纸。这两步算同一项操作的必要先后。纸背已经露出时保留原稿指定的不可辨状态。灯头降低、字迹因受光改变刚好能读时，再决定同镜收紧或切近。此前避免用清楚的年份特写。纸已经翻面，下一镜从这个状态继续。

**给演员和录音**　许等钟翻稳才动灯。钟仍用手压着纸角，不换手指字。两人最终共读，无人念字，也无需添加画外解说。若照明实测无论怎样压低都读不出，先试灯的方位和镜头反光，保留原稿“灯位变化带来发现”的因果。预演将具体年份留给作者设定。

**复查**　初读画面应明白是谁发现可能有字，余下两人何时真正读到。若剪掉一切还能用同一个镜头看清，固定拍完也成立。若原始画幅读不出细字，优先在灯位变化后给已有纸面一个局部，前镜不必再重演一次翻纸。
````

## 5. 审美设计与返修依据

资料库路径 `SKILL/director-assistant/references/art-direction.md`。范围为原文件第 1–40 行。

````markdown
# 审美设计与返修依据

在研究后、分镜前使用；新稿、局部修改和研究受限稿采用同样的设计底线。先组织观众看到的关系，再写质感措辞。这里只检查设计；没有可读取的成片时，不宣称实际构图、表演或视频审美通过。

## 意图、风格与底线

用户指定的剧情、动作、时长、镜数、渲染档位和强度属于当前约束。高饱和、大规模特效、极端机位、小景别与关键慢镜可以承担明确表达；不得以审美优化为由暗中降强度、删动作、改结尾或统一成低饱和慢文戏。技能中的高节奏打斗默认与显式滑块仍按现有规则执行，完成手法数量不能代替主次和因果检查。

共同底线是观看重点、必要信息可读、画面关系相容与情绪推进。高强度通过轮廓、纵深、亮度分配、先后次序和后果建立层次。允许有动机的短暂遮挡、过曝、停留、重复、对称和多人并重；检查前后是否兑现意图，不机械要求每镜只有一人、每镜换机位或每秒出现新动作。约束确实冲突时说明具体位置和可行取舍，不静默覆盖用户决定。

## 六项决定：从失败定位到修改

BCF 的 artDirection 保留以下六项，即使研究受限也须填写。每项指向当前镜头中可见的安排，不用质量标签凑字数。

| 字段 | 应确定的画面关系 | 失败表现 → 优先修改 |
|---|---|---|
| intent | 观众先知道/感到什么，哪一刻改变理解；人物想做什么 | 只有“悲伤/燃”，行为无转折 → 从已有事件设计可见的选择或反应，调整揭示时机 |
| visualHierarchy | 此时主要观看对象或人物关系，轮廓、面积、纵深、明暗和运动怎样引导视线 | 特效、脸、背景同时抢眼，关键接触重叠 → 调视点、错开动作峰值、分离背景；保留动作与规模 |
| lightColor | 既定世界光源、主要色彩关系、局部强调与材质响应 | 全屏等亮、每色都强调、跨镜随意换光 → 组织明暗与色块，把强调放在当前重点；不用统一降饱和修复 |
| rhythm | 哪个变化值得读清，何时推进，声音和动作如何交接 | 每击同等爆闪/慢放，或细节装不进时长 → 重分配镜内先后、镜长和强调位置；保留指定动作、镜数与关键慢镜 |
| signature | 由本场景人物、道具或空间产生的一个可记忆变化，并指出镜头 | 换任何角色和场地仍完全一样，靠额外奇观撑场 → 用已有关系形成具体落点；简单场景不强塞惊奇 |
| restraint | 为主效果让出注意力的非必要处理；也可说明为何当前复杂度成立 | 特写、运镜、音效重复表达同件事 → 合并/错开获准改动的处理，或保留承担升级和回返的重复 |

先内部比较两个简短可行方向，再选择适合当前目标与约束的一种；无需输出两份完整提示词或新增用户确认。差异来自观看位置、信息释放、调度或光色组织。向用户提出画面备选时也应用本表，不能把明显失焦或超载的方案当作有价值的选择。已给足拍法或局部微调时，聚焦相应范围。

## 参考与样例

实际研究沿用 [scene-research.md](scene-research.md)：优先用户指定的维度，再查具体已发行作品片段、分镜或制作人员解析。一般教程、海报和片名不能承担动作过程证据。比较不同作品的具体处理，并记录 work、scene、technique、来源逐字 evidence、adoption 和 shots；采用点必须能在正文定位，不照搬整段招式或原作道具。

来源只有文字时，只据其明确记载设计，不冒称看过画面或编造时间码。可读取静帧可校准构图、光色、轮廓与材质；调度、节奏和动作承接需要连续片段。没有视觉证据时，只作文本设计判断；原有研究受限标记仍适用。

需要设计对照或找不到具体修法时，按 [审美正反例](aesthetic-examples.md) 的索引只读最相关的一两组。这些是待用户认可的原创文字设计，不是真实影片分析、已验证成片或用户已认可的审美标准；不可拿来充当联网案例证据，不因样例而增加未授权剧情。维护者可用用户认可的截图/片段和实际结果逐步校准。

## 审核与维护

在现有 CG/表演审核开头按 [quality-gate.md](quality-gate.md) 记录最明显的一两处实际问题及修订后的镜头依据；原稿成立可保留，不为凑数找错。修改后复核用户约束、相邻切点、光源与时间。引用与字段通过只代表可追溯，不代表美感得到认证。

维护或评估框架变化时使用 [六道固定对照题](aesthetic-benchmark.md)，日常出稿不加载评测表。分开记录文本设计比较和真实成片比较，不把模型自评分当作用户审美结论。
````
