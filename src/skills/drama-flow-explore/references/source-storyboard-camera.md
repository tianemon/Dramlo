## 1. 镜头设计与接续

````markdown
# 镜头设计与接续

## 选拍谁，如何切

先写观众在本拍要从哪里读到变化。问话时可留在听者身上，回答可以画外传来。想让观众感到两人仍同处一个困局，双人镜可以一直保留双方的距离。要辨一张字条，再决定它在人物手里的局部是否需要切出。主观镜占据人物合理眼位，客观插入可以让观众先知。过肩要说明谁的哪侧肩在前景、是否挡住证据。

取景先定必要入画范围。说“中近景”还需确认桌下递物的手有没有被裁走。画面收紧时仍留在场但未入画的人，不要擅写离场。运镜交代起幅、触发、路径及落幅，移动未停即可切出。机位前后移、原地摇摄、变焦、转焦有不同后果。画内人物靠近造成的变大不能转成机位急推。对光线以场内来源为基准，反打时重新推受光侧，不能凭题材添雨雾、逆光或慢动作。

## 空间先于画面左右

记录门窗和活动区域，人物分别靠什么地标、朝向谁，互动轴从谁指向谁。每个机位单独推导主体的画面左右、前后景、可见背景和画外声源方向。对坐反打通常目光相向，站坐有高低差。两人并肩由背面切至正面，其屏幕左右可能对换。按真实机位写。若改轴会迷向，可见的跨轴、重新定向的同框或合适的中性视点能帮助观众辨认。

多人交谈看眼前哪一对正在互动。手持物、人员站位、伤势和朝向在真实走位后随之更新，门窗的世界位置不变。竖屏的纵深有助容纳多人，但锁定并排时须留下原关系。确需展示反常布局时，说清“桌子在谁和谁之间”“靠背贴哪面墙”等正面关系。斜侧视野确能同时见门窗，不能按正反打惯例强删一个。独立输入应能仅凭文字还原当前几何。简单空镜、物件局部或单人观察可省去整张俯视图。

## 表演、物理与声场

反应需发生在人物能获得足够信息之后，必要时指出句中哪一截。起态、变化和余势要落在可见部位。双手扶人时可以放慢步子，不能同时腾出手去攥拳。远景可看重心与路线，难以辨别细小嘴角变化。交接逐相核递出、接稳、松手及其先后，所有权与手上实际持有分开。切点可在接触过程中，切入应承接这个相位。受力、支撑、惯性须契合已定材质和姿态。非人角色只用已有器官或机械结构，普通道具或背景动物无需加表情。

逐句确认发声者、画内或画外、是否回放、谁能听到。关键拟音写明触发。持续底声和真实世界位置跨镜延续。画外说话、旁白和内心声音不要求画内听者对口型。无嘴角色标明已有声源。角色平时的音色和当句音量、节奏、重音分开写。多个发声者无音频时，可设计相容且能辨的听感，注明是设计。不要从身份推断口音或假称已对齐样本。安静的听者可以继续手头动作。有实质听辨需要才让背景声退让。配乐、硬字幕或新叹气须服从原稿和委托。

同一长句跨镜时，按各镜承担的词段拆写，合起来逐字还原。需在整段制作页集中录一次整句，也可只在起声处写全文，在后镜标明续声位置。译意供阅读时放在生成输入之外，以镜号、台词号对应。按译后语序和实际语言估时。先声后画或声留下一镜写清起止，声音跨切自身不增加成片长度。

## 接点复核

需要画分镜格时，按交付画幅画框，先摆出地标、轮廓、视线和画面边缘遮挡，再标本镜要看的动作。画框外标镜号、预计时长、关键台词或声音。区分人物运动箭头和机位运动标记。一个长镜可以用同号的起幅与落幅两格表示，明确两格之间连续拍摄。只有画法说明或文字草图时应注明相应交付形态。

连续接续比较实际保留的前一镜末和后一镜首，包括身体与视线方向、持物手、动作进度、速度、声源、光线和揭示状态。前段最后一个文件帧被剪掉时，它不能担任续拍的依据。连续段可同构，是否换视点由观看职责决定。一次技术分段不要求多一个摄影切点。明确“十分钟后”则按经过时间更新人物状态，同时保留仍成立的环境事实。要查动态接缝，需看接点前后若干帧并听接点两侧的声音。
````

## 2. 摄影、构图与调度

资料库路径 `SKILL/laotang-cinematic-storyboard-s10-free__老唐创作套件/references/camera.md`。范围为原文件第 1–102 行。

````markdown
# 摄影、构图与调度

<a id="c00"></a>
## C00 读取范围

新建排镜读C01—C03；选择机位、透视或运动读C04；光线/材质影响身份、证据或揭示读C05；多人在场、走位或状态接续读C06；有切镜、快闪或生成段界读C07；有角色表演承担关键变化时读C08。上述内部规划不因交时间总览预览而免读，完整稿也按实际触发项加载。只润色或忠实提取既有稿不重新选镜。光学与专业运镜词典仅按[camera-advanced](camera-advanced.md)触发，不整表默认加载。

内部判断编译到现有字段，不输出选镜分析或要求用户填表；四列预览按preview写清景别/机位/主运镜、关键动作与完整原话，不以一句话限制截断内容。阶段、授权、镜长和段界分别服从相应主流程。

<a id="c01"></a>
## C01 证据、观察对象与切点

先问观众此刻要读到什么、由谁/什么承载，再选尺度与覆盖，光学参数最后。选择者、信息承受者、第三人、手/物/空间都可作主体；说话者、主角或最激动的人不自动得特写。声音已交代含义而变化在听者就看听者，台词仍由原说者发出；听者获知不足只延续此前状态。

须同时判断脸、手、目标、接触或距离时保其关系；不能为拍反应漏掉唯一交接。局部变化需集中辨认才进特写，保起态和读清所需停留，再按新信息、悬念或注意变化离开。持续特写、固定长镜、无运镜无转焦均可由表演/信息/持续观察成立；同构或长本身不算停滞。

**长对话唯一判断**：逐语义节拍查信息、人物策略/行动、关系与持续体验是否清楚；只有必要证据读不清，或这些均无推进且有无职责重复时才调整。先去冗余，再在未锁定范围选择同框、过肩、反应镜、局部或镜内重构；不得为形式变化改锁定拍法。每镜一个主要观察目标，可容纳兼容次要信息；不一句一镜、按固定秒数切或预设镜数，不拆碎可连续完成的简单动作，不把复杂事件硬塞到不可读。

空间明确后可直接靠近，也可从有悬念的局部开始，不强制全景→特写。重大后果的反应可留原镜，不自动加空镜；指定等待、停顿、余韵、突变或连续冲击保持。情绪可由停留、距离、动作或声音表达，不固定紧张快推/悲伤远景；反向选择须更清楚，不为反常而反常。删并覆盖后复核实际时长和接续，不改锁定事件/原话。

<a id="c02"></a>
## C02 景别、裁切与构图

景别术语存在口径差异，执行稿写实际裁切、必要入画部位、主体大小、遮挡与可读时间，不以名称代替画面。

| 观看需要 | 比较的尺度及限制 |
| --- | --- |
| 地点/路线/相互位置 | 远景/全景容纳地标、全身、行动空间；太小的人物只用整体动作，空间已明可收紧。 |
| 身体策略、持物、距离或接触 | 中景/中近景按需保腰/胸以上及双手；手低于胸线就放宽，不裁关键触点。 |
| 态度变化与肩颈/手势 | 近景保承载部位；只有脸部变化可更紧，画外关系要读则放宽或换覆盖。 |
| 面部/局部选择证据 | 特写明确边界；已可读且更近无新价值可不收，保理解所需上下文。 |
| 极小证据/触点 | 大特写/插入标部位、归属、状态；不自动套微距、慢动作或浅景深。 |

同镜可因已有走位、机位移动或取景变化改景别，写触发与终点。收紧丢关键手、同时性或距离时，放宽或使用已成立覆盖，不以更近的脸牺牲因果。

**景别转换按观看职责**：依据需读信息的尺度、人物关系、空间定向和节奏选下镜。近景直接切双人中景、特写切全景或连续同景别都可成立，不要求逐档经过，也不设封闭的跳档例外。若切换造成无意跳动或方向迷失，修正实际视点、裁切、动作接点或必要的空间建立；不为过阶梯添无职责过渡镜。跨生成段遵循同一标准，不为技术分段制造尺度变化。

构图独立说明先看哪里、还须同时看到什么：主证据的画面位置/大小，必要视线空间或运动前方空间、前景遮挡、纵深/地标、背景分离；空白需有悬念、孤立或方向职责，字幕安全区仅用户要字幕时安排。不套九宫格或堆满术语。看向/运动方向通常留可用空间，有意压迫、逼边或藏目标就写明实际效果，避免被自动居中。换画幅逐镜重查双人关系、关键手部、道具、视线和行进前方空间，不把中心裁切当自动适配。

多人/多物有主次；背景不凭动作、亮度或细节抢唯一证据。遮挡若参与信息控制，写遮什么、由谁何时解除；无职责则不可盖脸/手/触点。原稿已有偷听、埋伏或暗中观察时，可比较前景窥视遮挡、干净视点或其他能保知情边界的拍法，不自动套遮挡。采用遮挡时只用已有物体，范围、虚实和受光按实际构图决定，15%—30%仅为候选构图参考而非配额；焦点反转仅在纵深与揭示时机成立时使用，不能提前露出秘密。没有依据不另加门缝、树叶或肩背。可读性不足先修裁切、站位、焦点和动作时机，再考虑加镜。

<a id="c03"></a>
## C03 覆盖、主观与空镜

- **同框**用于同时反应、试探、先后、距离或共同目标；按画幅与纵深/景深安排，装得下不等于读得清。
- **过肩**用于在场、观看方向、距离或遮挡参与关系；谁的身体哪侧肩、前景位置和谁为重点都明确。肩的大小/清晰度服从任务，不固定虚化。前景不能盖住关键表情、手部或证据。
- **干净单人**用于独立读表演或排除无用前景；保已建立视线/声源，不由单人画面推断孤独、决裂或对方离场。关系开始/转折/换位按需建立，无主镜/双方单人/过肩/反应各一遍的配额；高低与景别差有依据，不强求双方参数相同。
- **POV**来自人物合理眼位或明确主观位置，遵守朝向、高度、遮挡与可辨条件，可稳定且不必出手。过肩不是眼位；物件特写可为客观插入，不自动成为人物已知。客观插入可按既定结构让观众先知，看向—所见—反应能同镜完成，已清楚环节可省。
- **阅读/操作面**先定有效面朝谁、谁能看/接触，再选肩后/侧上方/插入/POV。观众看清不能改角色知情/可达；仅已有动作允许时调物件倾角，不因摄影需求另加展示动作。
- **空镜**为环境职责，物件局部证据另按插入判断。只用已有时空、路线、环境变化、缺席/痕迹、指定等待或声音/余韵的观察对象，不增天气/象征物/事件。离开人物前查漏何反应、镜外行动和声音如何延续；原镜能读必要反应先留人物。无新信息也可有既定持续体验，但计入预算。转空镜不默许人物完成未交代的关键动作，也不擅自暗示时间跳过。

<a id="c04"></a>
## C04 透视、运动与可行机位

大透视服务已有纵深、逼近、尺度、阻隔或冲击：明确近端部位/远端主体及关系，以近机位和足够视野容纳。不能凭广角标签建立纵深，不能改变世界尺寸或遮关键触点/身份，也不自动用于所有脸。俯仰/倾斜按上下关系、遮挡、尺度或主观体验选，不绑定善恶、地位或胜负。

表演自足可固定；固定时机位、朝向和焦距不暗变，不推拉、不摇移。集中局部可推、显露环境可拉、跟随/解除遮挡可移、注意变化可转焦。摄影机平移/转向/变焦与主体移动分开；变焦只改视野，没有机位移动的视差，不能冒充推拉。每镜一个主运动，写起幅、触发、目标、路径、速度倾向与切出位置/运动状态；实际停住才写停点。复合运动须说明先后或协同，不堆推拉绕升降清单；专业写法见[camera-advanced CA02](camera-advanced.md#ca02)。不设最低运动种类、特写率或出镜配额。

按已知墙、门窗、通道、障碍及高度查路径：拉远查后方、横移/绕行查沿途、俯拍查高度/遮挡，不只凭房间面积或焦距判可行。不编未给的精确面积/层高/距离；先选不依赖未知余量的构图，未知决定锁定画面可否实现才补缺或提替代。室内不一律禁景别；普通写实不得穿墙/穿顶/无路径绕行，用户指定虚拟/超现实除外。

强俯仰、倾斜、急移、手持须有观看作用，不持续遮住必要脸/手/触点。人物和道具都要辨认则保持两者清晰，不自动给特写极浅景深；转焦写A/B纵深、前后清晰关系及触发。已有遮挡/距离/受光/清晰度可组合建层次，不填满所有层，不增路人、摆件或背景活动；背景锚点的有限补充只按[space S02](space.md#s02)。

<a id="c05"></a>
## C05 光色与材质

主光来源、场内方向、软硬写清；有依据的天空散射、墙反射、窗外来光和画外灯可用，不必光源入镜或逐表面参数化。同场固定世界光源，反打画面受光侧可变；人物过遮挡、光移动或时间变化才引起相应变化，不能换镜就换照明。

光照服务允许看见与暂藏的信息，不一味抬亮或压暗。散射/硬光/轮廓光按场景，不默认夕阳、逆光、冷暖对打。可见光束要有光源与介质依据，不凭空添烟雨尘；已有雾也非每镜光柱。全局只定必要明暗/综合色彩/饱和，主色优先取已有环境衣物光源；同场识别连续，跨场/昼夜/已授权主观段可变，不硬套全片滤镜。

肤色、识别色、结构与照明/风格相容；阴影色不是色温，不编色码/胶片型号/开尔文数。颗粒、雾化、晕光、过曝、虚化各有职责，遮边缘/接触/地标先减无用效果，不用效果项数配额。材质只写本镜相关的变形、反射、磨损，延续干湿/破损，不全改湿亮、磨皮或额外纹理。先保脸/触点/证据局部可读，再控背景；冷暖、饱和、景深互不自动绑定题材/善恶。

<a id="c06"></a>
## C06 在场、空间与动作连续

多人内部区分在场可见、在场画外、已离场；收紧不等于离场，反打不需全员入画，回宽景恢复仍在场且应可见的人，不凭空消失/复制。明确谁影响谁、身体/头脸/目光对象、本镜观察谁，次要人物仅作必要活动。人物表演执行[acting](acting.md)，不可用镜头术语替代其具体行为。

互动、走位、反打或交接必须同时有当前画幅投影与稳定场内参照；具体站位四要素、走位四要素、身体左右与世界位置、手别及输入自足统一读[space S02—S04](space.md#s02)。人物的道具所有权与当前持有人分开。已确认全输入不变的必要状态可共享，后续写变化；每镜画面投影仍随当前机位写，跨输入不以“同上/继承”代替事实。

关键交接/围挡/接触写发起者、对象和结果，不能为兼顾所有人的反应漏掉改变归属/位置的瞬间；接触物理读[readiness R03](readiness.md#r03)。切出记录准备/接触/完成阶段，下一镜兼容承接，不重做已完成动作，不从准备跳到不可理解结果；刻意省略仍须因果可懂。

<a id="c07"></a>
## C07 连续剪辑、快闪与段界

切点回应动作阶段、视线落点、信息到达或延迟揭示，先定为何离开再定下镜对象，不轮流拍每个说话者。交流方向、目光与声源保持；正反打视线、越轴、出入画按[space](space.md)。普通相邻镜同主体/相近尺度时，检查无意跳动与无职责重复，优先有观看作用的视点/尺度/主次差异；约30°仅经验，不凑角度添镜，有意跳切/越轴须有表达依据。

**默认不越轴**：正反打、段界换视点、插入后回到人物，都留在关系轴同一工作侧。换侧只走已有的可见跨轴运镜、人物穿轴、中性插入后的宽景重建，或用户明确要求的直切；后两种按[space S05](space.md#s05)声明对调和地标。需要段界切换时，不为制造差异而越轴；留轴线同侧按观看需要选择尺度和视点，也可同构接续。

**生成大段边界**：技术分段不自动成为摄影切点。有新观察职责时可换尺度/视点，连续表演、持续观察或已定长镜有依据时可保持同构，不限用户点名的特例。是否能无缝接续另核入口与真实媒体，不以尾图或文字保证。完整判据归故事S7；预览体现实际镜头结果，完整稿给必要接续说明。

插入用已有相关物件/身体/环境，单证据可独撑一镜、不要求露脸，不用无关空镜遮必要动作，不默认每镜转场特效。跨场可用已有动作/形状/声音连接，有意硬切不强行平滑。声桥、续声与画面时钟由[audio AU04](audio.md#au04)统一：只有声音跨切不加画面秒，独立输入拼音轨说明留完整稿块外。

快闪仅用户要求或原故事需要时使用，区分当前动作切片与记忆闪回，不把普通受击变回忆，不默认重击声、回现实或静音结尾。成片占用和完整生成素材L分开：短剪辑目标不等于入口可生成秒数，按入口支持素材加余量再剪连续区间；全片从0到采用T连续覆盖，黑场停顿计时，叠化按并集一次计T/D而不缩L。全规则按路由容量，不附未落位快闪；仅已知fps才把秒换帧。剪取要保所需起止状态及接触/结果，不能只截起势。

交付只走质量检查一轮，不把专业深化加成默认前置或额外验收轮。

<a id="c08"></a>
## C08 摄影为表演留证据

在已定镜头内确定本拍真正要读的变化：人脸、整体轮廓、动物耳尾、机体朝向、已有手部/机构或对手反馈。先让该通道有可见尺寸、对焦和受光，再选择运动；不因“演技增强”全片改特写。小表情与关键交接同样重要时，优先选一个能同时读清两者的取景；不为“演技增强”加反应镜、插入特写或补拍覆盖，镜数仍按C01和story判断。

背面不能读嘴角，拉焦前后写清谁能看清；表演发生在运动/转焦中可以成立，但关键变化不能在不可读时已经完成。无脸角色依轮廓、朝向和节奏可读性选景别；大幅表演可在宽镜完成，近景也允许真实爆发。稳定构图可持续有戏，无需为了避免“生硬”固定每秒微动、每镜换尺度或新增摄影机运动。
````

````markdown
# 摄影深化（低频分节）

<a id="ca00"></a>
## CA00 明确加载条件

普通固定/推拉/跟随等任务先用camera核心，不读本文件。用户给出焦距/FOV/光学疑问，只读CA01；命中特定专业运镜，只读CA02的该行及总则。关键场次的拍法比较按[story S4](story.md#s4)在内部简要完成，不加分析字段或额外交付轮。

<a id="ca01"></a>
## CA01 光学口径

36×24mm全画幅、直线投影的近似**对角**FOV：24mm约84°、50mm约47°、85mm约29°、135mm约18°；同机位从宽环境到窄局部。不是水平FOV或平台参数定义，画幅裁切会改变实际视场。

透视由机位位置主导；保持主体景别时后退机位常带来背景压缩，不能归因于焦距本身。景别还依主体尺度/距离/视场，景深依光圈/对焦距离/画幅，不把焦距绑定距离、浅景深或锐度。一般选焦距或明确口径FOV之一，再独立写景别/机位/运动；如85mm＋中近景＋平视＋推近并非重复，其他参数只有实际需要才加。

<a id="ca02"></a>
## CA02 运镜词典与复杂路径

先按camera判断动机与可行性。专业名称后补看得见的运动；器材名（无人机、摇臂、轨道、稳定器）可能入画，优先视角/机位描述，实际误生器材时换写法。一个主运动，必要组合说清先后/协同；写起点、方向/路径、速度、终点或切出中状态，停住时落幅有人与画面侧；实际仍动不得写成停稳。

| 运镜 | 实际是什么 | 写法要点 | 常见误写与陷阱 |
| --- | --- | --- | --- |
| 固定镜头 | 机位、朝向和焦距全程不变，只有画内的人和物在动 | 写“固定机位，镜头完全静止，不推拉、不摇移”，再写画内动作 | 只写“固定镜头”时，模型常自行加缓慢推近或漂移；必须静止就把这几项都写上 |
| 推 / 拉（含轨道推拉） | 机位朝主体靠近或远离 | 写从什么景别到什么景别、推到谁身上停 | 不同于变焦：变焦时机位不动，前后景没有相对位移 |
| 摇（水平摇、上下摇） | 机位不动，镜头原地转向 | 写“镜头原地向右（或向上）转，从[A]摇到[B]”；需要时补“画面内容向左滑过”。可附 pan / tilt | 不是“镜头向右移动”，平行移动叫横移；只写“向右”时，模型可能理解成画面内容向右移 |
| 横移（含轨道横移） | 机位沿与镜头朝向垂直的方向平移 | 写镜头朝向哪边、机位向画面左/右哪侧平移，例如“镜头朝向橱窗，机位沿街向画面右侧平移”；跟着谁、停在哪 | 机位朝走廊深处拍、顺着走廊前进，是推进或跟拍，不是横移；跟着对话的两人横移时，机位仍留在轴线同一侧 |
| 升降 | 机位整体升高或降低 | 写起止高度，例如“机位垂直升高，镜头保持水平”，必要时再写“同时略微下摇，保持主体在画面中” | 只写“镜头向上”，会被画成上摇（机位不动、仰头） |
| 摇臂 | 机位沿大弧线升降，常带横向位移 | 写起止高度、横向方向和落幅，例如“机位从人群头顶高处缓慢下降并向画面左侧移动，落到甲的中景” | 同时升降又横移就是复合运镜，按本节末尾写主导运动和起止状态 |
| 跟拍（前跟、后跟、侧跟） | 机位随主体移动，保持距离 | 写机位在主体前方倒退、身后还是侧面；用景别表达距离（如“保持中景跟随”），写主体在画面哪侧 | 不写具体米数；侧跟时主体的行进方向就是银幕方向，前后镜保持一致 |
| 稳定跟随 | 机位平稳流畅地跟随，路线自由，没有晃动 | 写“平稳流畅地跟随[人物]穿过[地标]，没有手持晃动”，以及跟随位置和景别 | 和手持在同一镜冲突时只保留一种 |
| 环绕 / 弧形 | 机位沿弧线绕主体移动 | 写起点在哪一侧、绕多少度、终点在哪一侧；绕过90°时写落幅里谁在画面哪侧 | 绕过两人连线就是越轴，按[空间越轴S05](space.md#s05)写明对调后的左右 |
| 滑动变焦（希区柯克变焦 / dolly zoom） | 机位移动同时反向变焦，主体在画面里大小不变，背景透视改变 | 写“主体在画面中大小不变”，再写方向：机位后退同时变焦推近时，背景逐渐逼近、显得变大；机位前推同时变焦拉远时，背景向后退远、空间被拉长 | 中文里的“变焦推拉”通常指普通变焦，不要用这个名字；不写“背景严重扭曲”，容易被画成鱼眼畸变 |
| 光学变焦 | 机位不动，只改视野 | 写“机位不动，镜头变焦推近，画面等比放大到[主体/景别]，前后景之间没有相对位移”，速度另写（缓慢或急推） | 不能代替推拉；背景压缩感来自机位远，不是变焦本身 |
| 快速变焦（急推 / 急拉） | 机位不动，短时间内急速变焦 | 写“机位不动，镜头急速变焦推近到[主体/景别]，约半秒完成” | “快速推近”会被理解成机位冲上前；要变焦效果就写“变焦”“画面等比放大” |
| 拉焦（转焦） | 焦点从A转到B，通常机位不动 | 写A、B各在前景还是后景，转焦前A实B虚、转焦后B实A虚，由什么动作或声音触发 | A、B必须在不同纵深才看得出转焦；转焦前后两人的必要信息都要可读 |
| 手持 | 机身带呼吸感的不规则晃动 | 写晃动强度（轻微/明显）和用途 | 需要看清的脸、手、证据不能被持续晃动遮住 |
| 甩镜 | 快速摇镜，带运动模糊，常作转场 | 写从哪甩向哪、在第几个镜头（入口为 Seedance 2.5 时可写第几秒） | 不能用甩镜遮掉必须看见的动作；作转场且两镜分开生成时，前镜结尾和后镜开头都写同方向的甩动模糊 |
| 主观镜头 | 机位在人物眼睛的位置 | 写“第一人称视角，[人物]本人不在画面中”，以及这个人的手是否入画 | 画面里不出现此人的脸和头（镜面倒影除外）；输入里带了此人的参考图时更要写明，模型常把此人画进画面 |
| 航拍 | 从空中移动拍摄，从低空掠过到高空俯瞰都有 | 写高度、方向和俯角，例如“高空俯瞰视角，缓慢向前飞越河面” | 器材名可能入画，见本节开头 |
| 一镜到底 / 长镜头 | 较长时间不切，可由连续表演、场内调度或摄影机运动推进；固定机位亦成立 | 按时间段写机位路径和人物调度，例如“0—4秒跟随甲进门，4—8秒停住，转向乙” | 超过平台单次时长时先说明限制；只有用户授权连续分段/延长，且入口支持所选接续机制时，才拆为多份并写清接缝状态，否则按路由处理冲突，不自动承诺首尾帧接续或暗中切镜；保留长镜头的职责以[camera C01](camera.md#c01)为准 |
| 遮挡揭示 | 前景物挡住画面，移开后露出主体 | 写挡住的是什么、怎样移开、露出谁、露出时在画面哪侧 | 揭示时机服从故事第三步的知情边界 |
| 穿越 | 镜头穿过门框、窗口、缝隙进入另一空间 | 写穿过的东西长什么样、穿过前后各是什么空间 | 写实场景不能穿墙，用户要求超现实时除外 |
| 荷兰角 | 画框绕镜头光轴倾斜，倾斜角度固定 | 写“镜头绕光轴倾斜约15°，地平线和门框从画面左低右高” | 不是让建筑或人物本身歪斜；和运动中旋转的镜头区分；不当成“紧张”的默认写法 |
| 俯拍 / 仰拍 / 顶拍 | 机位高于、低于主体，或在正上方垂直向下 | 写机位高度和角度大小；顶拍写“镜头垂直向下” | 只写“正上方”可能被画成大俯角斜拍；不把仰拍固定等于“英雄”、俯拍等于“弱小”，按要显露的上下关系选 |
| 子弹时间 | 主体动作定格或极慢，镜头环绕 | 写“时间几乎静止，摄影机以正常速度环绕约[角度]”，并写哪些东西一起静止（水滴、碎片、头发） | 模型常把“极慢”也套到摄影机上；环绕角度大时同样涉及越轴 |

复合运镜拆成“主导运动＋起止状态”来写，一镜只保留一个主导运动；不越过关系轴，越轴按[space S05](space.md#s05)。原稿/用户已指定慢动作时保留并计入真实总长，不新增慢放凑时长。
````

````markdown
# 空间、机位与连续投影

<a id="s00"></a>
## S00 读取范围

S01是所有新建/细化镜头的判定入口。满足完整蓝图条件读S02—S06；单人轻量只读S03的机位/目光及S04适用动作，不读多人布局；空镜/物件插入/POV按S01例外。仅换文字呈现或流程C不补空间。示例只在对应问题难以表述时读[examples E-S](examples.md#e-s)。

内部定真实世界关系，再随机位推导本镜画面左右/纵深，不能换视点后照搬旧左右。关系必须成为可见几何；稳定布局与当前投影分开，反常布局正面说清。时间总览预览不输出空间图、机位清单或附录；这里只为内部排镜与完整版提供依据。

<a id="s01"></a>
## S01 启用与豁免

任一情形启用完整蓝图（会交流的拟人动物、机器人等角色计入“人”；背景动物、睡着的宠物和普通道具不算）：两人以上同场且有对话/交接/走位/正反打；布局不同于常见画法；竖屏多人；两人以上同场分多份输入或系列反复回同场景。

单人即使分输入或走位，只在景别与摄影机写地标机位/背景，在动态时间轴写运动/视线画面方向；看画外人注明朝画面哪侧。不强写场景布局、身份标签或空间示意。空镜、物件插入、POV、天空水面等无可挂地标时，只写观察方向及必要参照，不编地标凑格式。流程C只保原稿已知空间，未知不补导演。

<a id="s02"></a>
## S02 内部世界蓝图

按需记录以下信息，不原样变成长分析交付：

1. 主视方向，如入口→电视墙；作为稳定布局的观察基准，不代替每一机位的实际投影。
2. 固定地标优先2—4个已知且可分辨的门窗/家具；记相对位置及可见侧。原地标不足可补1—2件仅作背景、无人接触且不参与剧情的固定陈设，完整版块外列本次设计；用户限制不添物时服从限制。
3. **可见背景与条件互斥锚点**：按既定地标位置、机位朝向、视野与遮挡推导当前背景。只有真实几何证明X与Y在该机位不可能同见时才写互斥，不能由对峙/反打题材直接推出“拍A只见X、拍B只见Y”。合法斜侧或宽视野可以同见两个地标；裁外写画外，不删掉实际应可见的地标来凑锁。此方法保留为防空间漂移的条件工具，不能替代关系轴与投影检查。
4. 人物锚位：在哪个地标的哪侧、坐/站、朝哪、接触距离；同锚位不叠人，并排同家具分各端，不新增人物。未指定时可比较对立者隔物相对、对话最多两人间不隔第三人、重要人物不要都背对、需用门在相应人可见方向；不是强改原站位。
5. 名字与可辨身份标签：取用户/参考的一个特征，同服装状态段稳定；换装或状态改变同步，不强锁衣色全片不变。无特征用名＋锚位/持物，不编服装；这是定位而非重复外貌设计。已有角色参考图时，静态外貌由参考图承担，正文不复写，只写动态姿态、泥水汗湿与新增破损。
6. 当前主要互动/运动轴和有效机位侧。三人以上按本拍主要行动对更新关系轴，用同框、地标或可见走位定向，不硬锁所有人全片画面位置。
7. 主光固定到场内来源/地标，再推各机位画面受光侧，不用反打后屏幕侧变化判断换光。
8. 内部机位清单：可编内部代号A、B、C……；记相对地标的位置、朝向、背景、主光投影、谁在左右前后、各自视线；先复用，真实信息需要才添机位。代号只用于内部核对和块外空间示意，执行代码块内每镜展开为地标描述，不写“A位”“机位B”。
9. 与常见画法不同的1—3处及必要越轴计划；没有差异不凑项。
10. 多人追逐/打斗/救援/交接/狭道时记录路径：起点、目标、方向、障碍/地标、触点、停点/出画；主体移动与相机移动分开，轴线/投影变化及时更新。静态对话、简单单人无需路径图。

站位检查“在哪、相对谁、身体/头脸朝哪、看哪”，普通两人可用一两句满足；身体方位必须具名并有朝向。转身只改以身体定义的左右前后，不代表另一个人位移；稳定世界位置用地标保存。

<a id="s03"></a>
## S03 写入完整版

启用时每份输入的【全局光影画风】后有【场景布局】，通常4—7句：空间与主视方向、地标及确有几何依据的背景约束、人物锚位/标签/关系、允许机位侧、当前成立的画面投影、必要反常说明/人数锁、连续性。未揭示者不提前写入，或明确本输入不出现；单镜独立只有一人入画时注明本输入只见该人。

**复用只限未变事实**：同场景的世界几何、未变布局与同侧机位规则用固定措辞；人物发生走位、状态改变或关系轴更新后，每份输入按其实际起态更新锚位/朝向/投影，不为逐字一致把人写回旧位置。越轴或换主视方向同步相应侧与投影句。布局图规定的几何在文字中同样存在，不上传图也完整。跨输入仍须把当前必要状态写全。

每镜【景别与摄影机】用“在何地标/区域哪侧、朝哪拍、背景是什么”，角度仅补充。起幅有谁/各在哪，有运动写路径/跟谁，落幅或切出状态明确；固定时不平移、不转向。同机位复用机位措辞，可只改变景别；不误锁人物动态状态。

每镜【空间与主体】按本机位重写画幅侧/纵深、面对/背对/侧对、人物之间隔什么。单人镜写位置、脸朝向、画外对象方向；视线另句，别把目光方向混成人物位置。“对面/身后/旁边”配地标或当前画面方向。某人近机位时，明确肩入不入画，避免自动过肩。

有意在画外的地标明确画外；近景容不下窗时写“左侧画外窗，只见左来光”，不硬要求画内窗。人物看摄影机身后目标时，身体/头分写，目光落镜旁而非直视镜头；只有原动作允许头转则身体保持，不同时要求矛盾正面/侧脸。具体句法在[examples E-S](examples.md#e-s)。

<a id="s04"></a>
## S04 动作、目光、手别与方位

目光写对象及当前画面方向，转移写从何对象/侧到何对象/侧。倒下/转身/伸手/走动也给方向。有实质走位写目标、画幅路径、切出地点及状态；到达才写停点，仍走则保方向、位置和步态阶段，简单动作可直述但不丢关键关系。真实路径与当前投影决定进出画；同向横向且相容机位时常右出左入，纵深/转弯/换机位/省略剪辑不机械套用。

切出状态携带姿态、位置、朝向、目光、持物手/持有人、悬空/接触、伤势、破损和干湿。所有权与持有人分开。一个输入内确认不变的必要事实可共享，之后只写变化；跨输入必要事实重写，不用“同上/继续上一镜/保持原样/回原位”。同输入已有明确起态后可用“仍/继续”。

躺卧写头靠何端、身体腿向哪、着垫侧、脸朝哪；特写补头顶方向，不能只写头枕扶手。看正后方须肩随头转等符合身体的动作；要求躯干不动，就将目标处于已知的身后偏侧，原文约120°仅作避开扭颈的写法参照，不把未知人体转角当实测，也不擅移锁定道具；冲突时修拍法/报告约束。

关键物原文未指定手时，选靠镜头侧以保触点。选定后全场不换手；之后某个机位让这只手转到远离镜头一侧，就接受部分遮挡或调整机位，不悄悄换手。原文指定手以原文为准；明确换手须有动作和连续状态。

裸“左/右”指当前画面，身体左右具名；世界布局里的左右以已声明主视方向为基准。地标方位需明确观察基准，东南西北可用于内部世界图，执行稿优先画面/地标参照。“靠近/远离镜头”仅描述本镜投影，不定义持久布局或机位；用沙发靠电视一端，不用沙发靠镜头一端。

<a id="s05"></a>
## S05 反打、竖屏与越轴

同组关系轴与相容机位下，反打两人视线相反；位置可变但目光不无故反向。高度按真实站坐匹配，站者向下、坐者向上。过肩写谁身体哪侧肩、前景大致范围/清晰度、看谁；不入画明确连肩也不入画，允许入画明确画面边缘，非一概虚化。

竖屏未指定站位可优先纵深，实际并肩按原文；前后景随机位重新推导。三人以上固定名字/标签和锚位，说明画内/画外与成组对象，外形近似群演用稳定编号。多人背影/远景需标签，单人轻量豁免仍有效，无身份特征可用名＋锚位，不编衣服。

默认留轴线同侧。并排同向者背后→正面会左右对调且越轴，不强镜像锁旧左右；面对面对话、世界位置与关系轴未变且同工作侧时保持相容投影，走位/新轴/越轴则按实际更新。越轴选：可见跨轴运镜、人物穿轴、中性轴线上镜/不含方向性视线的插入或空镜、宽景重新建立。正对双人同框不自动算中性镜；单纯另开生成输入不替代观众的重新定向，仍需可读关系/地标。

越轴镜说明换到哪侧及对调后左右，后镜按新侧写。用户锁定不加过渡的直切可保留，但该镜须声明对调、至少一项两侧可见地标帮助定向、完整版块外提示短暂迷向风险。地标/光源投影应与机位清单一致；正常反打光侧或背景换侧本身不等于越轴。

## S06 建立镜、反常几何与审阅示意

整片连续模式同场第一份输入、越轴/重建后的首份输入，第一个多人镜原则上较宽且能辨主要人物及至少两个地标，不远到人脸/身份丢失。例外：单镜独立；空间已建立且接续清楚的后续段首镜；有依据的同构/同首帧接续；延迟揭示的局部开场；用户锁定开场。例外靠本输入布局与适用参考定向，锁定开场补足必要地标/左右；空镜或插入开场后第一个多人镜承担建立。建立不另设固定秒数。

异于常见几何的布局用正面可见关系说明，可再加一句短否定；只说“不并排”不够。客厅沙发朝向、隔桌而坐、右舵、躺卧方向、门不居中、围坐空位/人数等实例迁到[examples E-S](examples.md#e-s)，只有命中问题才读，不把全部反常例表塞进每个任务。

完整版启用完整蓝图时，仍在第一个输入块前给一次空间示意：不超过8行俯视文字草图＋逐机位清单，标“审阅用，不投喂”；输出模板只决定呈现格式，不能因预览变简而取消完整版空间能力。用户最新时间总览预览不输出该示意、图片建议或折叠附录，内部蓝图仍必须做。改布局同步蓝图、场景布局、机位、视线、尾态；对用户用“摄影机所在一侧”等直白词，不铺内部术语。

空间验收交统一质量检查一轮：盲读完整版能画出布局/机位/投影，不用另开空间检查轮。空间参考图与构图图设计属于至臻完美版能力；本版用文字【场景布局】与逐镜机位保证空间自足。
````
