## 1. 底层共性与制作路线

资料库路径 `references/制作知识库/通用/01-底层共性与制作路线.md`。范围为原文件第 1–24 行。

````markdown
# 底层共性与制作路线

## 创作真正要控制什么

| 层 | 需要决定 | 最常见的误判 |
|---|---|---|
| 叙事 | 观众此刻知道什么，下一拍为什么值得看 | 用精致空镜掩盖故事没发生变化 |
| 表演 | 人物想做什么、被什么阻碍、观众能看见什么反应 | 把「震惊」「紧张」当成可执行动作 |
| 空间 | 谁和谁、谁和门/道具之间的实际关系，相机站哪边 | 让一块屏同时正对角色和相机，却没改镜位 |
| 时间 | 状态如何变化，动作何时结束，哪里可以切 | 两段首尾帧一样，就以为速度、方向和声音都接上 |
| 声音 | 谁在说、谁听见、有什么背景，静默是否是设计 | 把 BGM、对白和环境声全交给每条短片 |
| 生产 | 什么锁定、什么允许漂移、因何返工 | 用每一条样片的最高画质证明整集可生产 |

镜头是一个信息单元，不是固定 5 或 7 秒。一个镜头有时只有一次动作和一个反应，两个任务也可在同一个镜头完成，不以时长凑复杂度。

## 真实制作主线

剧本与人物约束 → 分场与节拍 → 关键资产 → 分镜及镜头卡 → 静帧/动画草稿粗剪 → 镜头生成 → 选片/补片 → 对白、音效和配乐 → 精剪、字幕与质检。流程会迭代，但已批准的成果先锁版本，不是回到第一镜重抽。

**先做最小完整回路。** 第一集先选四个不同功能的镜头：建立位置、呈现动作、给出反应、结束在变化后。缺一个镜头即可用有标记的静帧占位，把整场放到时间线上看清节奏，再决定哪两条值得重跑。不要在第一个镜头定稿前把整集搁住。

## 人和 Agent 的分工

导演决定取舍：观众看到什么、什么时候知道、哪条表演最对。Agent 负责拆分、检漏、材料管理和按已批准方案执行。生成器提供候选，剪辑决定观众最后看到哪一刻。核心动作、关键台词和叙事事实是硬约束；雨滴数量或背景闲置细节通常是软约束；不影响观看的毛刺可列入允许偏差。
````

## 2. 故事、剧本与分镜

资料库路径 `references/制作知识库/通用/02-故事剧本与分镜.md`。范围为原文件第 1–24 行。

````markdown
# 故事、剧本与分镜

## 四层文档不混写

1. **故事大纲**：人物的欲望、阻力、选择与后果，以及本场在整集中的功能。
2. **世界和连续性账本**：事实、时间线、谁知道什么、关系、伤/衣着/道具状态；区分已批准事实与候选设定。对白不得让人物无故知道观众已经知道但他不知道的信息。
3. **剧本**：镜头可见的行动与可听见的台词。心里话先选表达方式：说出口、画外内心旁白，或完全不出声让观众看反应。三者不是同一条音轨。
4. **分镜/镜头表**：把剧本节拍映射到视听，不逐句机械切镜。为一个镜头写清它为何存在、预期观众看到什么、能在哪个状态切出。

## 镜头卡应留下的决定

镜号（稳定标识，不随拖拽改号）、所属场和剧情时间、镜头任务、起止状态、机位/景别/视线、人物站位和道具、重要动作顺序、上下游依赖、可听内容、参考策略、允许变化、验收及备用剪法。

- 建立镜头交代方位；动作镜头给因果；反应镜头让观众读懂后果；插入镜头给关键信息。不是每场都逐个使用。
- 给短镜头一件最重要的变化。动作顺序讲清楚，能靠画面看懂的事不要再让角色解释一遍。
- 如果必须同时看清角色反应和手机内容，不默认让手机漂浮或回头给观众亮屏。可以先看角色注视，再切到符合眼线的屏幕插入。不能切时，改变合理机位或只让观众看到反应。
- 人物进门要说清从哪个空间经过哪道门进入哪个空间；在分镜画出俯视站位比反复加方位词更容易发现冲突。
- 情节越重要，验收条件越早定。例如「观众能看懂他先看到通知才停住」比「画面有电影感」更容易检查。

## 验收

拿掉对白看画面是否仍能理解关键因果；只听对白检查是不是自然说话、是否说了不该知道的事实；再按镜号把镜头卡排成粗剪，验证信息顺序、人物动机、动作接点和节奏。粗剪不通先改镜头设计，不先追加高清渲染。

参考：[Columbia 电影术语：视线匹配](https://filmglossary.ccnmtl.columbia.edu/term/eye-line-match/)。
````

## 3. 视觉资产、摄影与连续性

资料库路径 `references/制作知识库/通用/03-视觉资产摄影与连续性.md`。范围为原文件第 1–26 行。

````markdown
# 视觉资产、摄影与连续性

## 三种不同的参考对象

- **身份资产**：角色脸、轮廓、发型、服装和道具；场景有不变的结构、入口、光源与可换角度的布局。把身份图、服装变体和已接受的镜头分开维护。
- **构图资产**：首帧、尾帧或关键姿态，锁一个具体时刻的镜位、人物/道具位置和大小。保存时绑定画幅、镜号和版本。
- **行为资产**：动作、相机移动、说话节奏和音色。参考需标明要借哪项；不要用同一份素材不加区分地约束所有东西。

远景的脸只有少量有效像素，多人站得近也更容易把姿态和面孔混在一起。重要表演尽量给面部可辨识的镜头，且用目标构图验收，不能拿单人近景代替双人远景。准备角色资产时看正面、侧面及常用表情；不意味着把所有视角无脑塞进同一次模型调用。

## 摄影与空间

- 景别服务信息：大全景交代关系、近景读反应，不用一味追近。保持角色在画面左右关系与视线方向；越轴不是禁令，但有意换边要让观众重新建立方位。
- 运镜和演员调度分开：镜头推近不等于角色向前，变焦不等于机位移动。先规定相机是否固定、沿何方向移动、什么时候停止，再决定焦点发生什么。
- 用具体光源和画面用途约束光线。相邻镜头保留光源方向、主色、时段和曝光逻辑，不必数值完全相同。
- 空间难生成时先用参考图、平面示意或简单 3D 锁住门、窗、道具和镜位，再做细化。参考画幅若与成片不匹配，先决定裁切还是补画，不能把变形留到生成后再补。

## 连续性分三种

1. **故事连续**：上一镜完成的动作不要重演；衣服、伤、道具持有者和在场人物数量不跳。
2. **感知连续**：切点处方向、速度、视线、景深、光和声音不使观众迷失。上一镜的实际末帧能提供构图，但不能替代检查速度与声音。
3. **剪辑连续**：有意切到另一角度可用反应、视线或动作匹配，不总需要上一镜尾帧当新机位首帧；同画面续拍才优先用实际尾帧。需要精确落点的用双帧，视觉身份稳定但镜位自由时先用角色/场景参考。

**验收**：查看首、中、末帧，再正常速度看动作。关心角色、手眼方向、门两侧空间、道具是否接触合理、屏幕内容是否贴在真实屏面。角色对着远处对象而不是镜头，否则漂亮也不是正确镜头。

参考：[Columbia 电影术语：视线匹配](https://filmglossary.ccnmtl.columbia.edu/term/eye-line-match/)。
````
