# 资产参考图

适合做稳定的角色与环境资产，不写连续动作。只在实际能用的参考图模式下声明图像绑定。输出独立 prompt、资产 ID/版本、参考图分工、参数、验收条件。

- **人物定妆**：锁脸形、五官中真正有辨识度的特征、发型、体态比例、服装版型/材质/颜色和标志物。指定取景、视角、表情、无遮眼的照明。先定一张主视图；需要背部或服装结构时才补同版侧面/背面，不默认一张拼多格。多视图出现冲突时以通过的主视图为准并标注待重做。
- **服装与道具**：写色块、结构、材质磨损、相对大小、正反面差异和拿取方式。佩戴物写在人物自身左/右哪一侧；不要混用画面左右。可重复使用的道具设计与该镜的开合、破损、归属分开。
- **场景**：以可复现的平面关系为先。写进出口连到哪里、重要物件相对位置、远中近层次、主光源和方向、可通行路径。需要两机位时从同一布局出图，不让第二视角重造建筑。天气、灯亮灭、道具状态按场次版本记录。
- **多图组合**：逐张标明输入序号和唯一职责，如图1取脸和发型、图2只取服装剪裁、图3只取场景布局与右侧窗光。写清冲突优先级、不继承参考图的文字/姿态/机位/额外人物。用已审素材，不用未编号图名或不存在的附件。
- **编辑**：先写只改的区域与目标，后写保留项。要求像素级不变时，交由遮罩与合成流程约束，别承诺只靠提示词就能像素级锁定。颜色、风格或服装等大变化按任务拆开验证。
- **输出参数**：分辨率、比例、透明、格式、质量写在调用参数栏，仅选当前接口/节点验证支持的选项；不要把它们仅写成“8K”等装饰词，也不承诺能力相同。

参照 [模板和实例](references/asset-recipes.md)。主要人物脸必须可辨时用足够景别或另给特写；宽景远处的人物优先守正确人数、布局和轮廓，不用“每张远脸超清”化解构图问题。
````

# 资产图模板

先写用途与画面；其次写核心主体/空间的确定信息；最后写参考绑定、保留项和排除项。模板中的内容须填实，不传占位符。

## 单人定妆（原创示例）

单人胸像，略偏正面的四分之三视角，双眼可见；石灰色纯背景。成年骑士，方下颌、有浅雀斑的鼻梁、后梳的栗色短发，左眉外端一道浅断眉。暗银色半身甲配深靛蓝粗呢斗篷，古铜圆扣别在人物左肩，胸口没有文字和纹章。柔和偏暖侧光从画面右侧进入，皮肤和织物保留自然质地。表情放松，保持自然身材比例；不加头盔、额外配饰或其他人物。

## 场景参考（原创示例）

从石桥西端朝东看城门。门洞偏画面右侧，左侧是一排贴墙木桶；桥中央留有两人并行的空道，右前景低矮石栏引向门洞。远处灰天的光从画面右上方落到门槛，墙内较暗。画面不放人物，门洞轮廓和木桶位置是后续反打机位必须保留的地理依据。

## 只改服装（实际上传两图才可用）

图1作人物身份与机位基准：保留脸、发际线、肤色、体态、姿势、构图、背景。图2只参考斗篷的版型与布料；把图1的斗篷换成图2的粗呢斗篷，保留图1已有的圆扣位置。照明方向不变，新增布褶要贴合人物姿势。不复制图2的人脸、姿势和场景。
````
