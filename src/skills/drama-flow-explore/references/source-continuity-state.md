````markdown
# 连续性与定稿状态

## 本场依据

确定当前载体、采用版本和场次切点，回到已认可正文的对应句，连同相关的作者决定及生效时间核对。大纲可规定将发生什么。判断这场之前读者看过什么，要从实际呈现的原文取证。试稿、弃案、人物计划和传言保留各自身份。

## 检查或交付状态

1. 先按故事时间看进场条件。追影响当前行动的人、位置、物件、伤势、权限、欠情或约定。对信息分别问谁从哪里得知、相信几分、何时才可据此行动。一次公开播送只证明消息可接触，具体角色是否听到还需场内依据。
2. 再按阅读或播放顺序核对信息第一次出现的位置。观众早见的动作可以构成悬念；某角色已知却暂缓向读者揭露时，保证他的言行仍符合当时判断。多线先逐线核时地，再按交错顺序查切回时能否接上关切。
3. 遇到重排或换版，找原场首次建立的线索、权限、代价、关系承诺与读者等待，再沿使用者追踪。替换、前移和删除造成不同影响。仅在当前授权内补接；未获授权的衍生版本列出实际受影响处。
4. 按请求给本场状态摘要、带依据的冲突定位、移动后须补的场次，或实际更新指定记录。遇到版本分叉、回写或多时序时读[版本与回写实例](references/version-ledger.md)。

## 验收

挑当场最需要依据的一次判断和一次资源使用，分别倒查获得渠道、适用条件和原文位置。顺读刚修改的位置及下一个真正依赖它的场次。计划里的伏笔仍未写、传言真实性未明或当前场次缺失时，准确标明未知及影响。

## 最小交接

给下一位写作者当前认定的版本与切点、已经发生的变化、角色之间仍有的信息差、此刻可用或已耗尽的条件，以及仍待兑现的事。只记录影响后文的差量，并把每项定位到场、段或作者决定；小段落可用一句话完成。
````

````markdown
# 变更定位与正式回写

沿用项目已有的记录方式。缺少统一编号时，可以用稿名、版本或日期和唯一场名、短引定位。

| 依据 | 当前可以确认 | 可能被误用的推论 |
| --- | --- | --- |
| 作者已定，第七场梅把铺面交给祁管理 | 后续方案须尊重这项安排 | 第五场已有正式授权 |
| 小说二稿第四场，梅在柜台后读到通知 | 梅已读；该段已向读者呈现 | 门外的祁也读过 |
| 剧本一稿第四场，保留信封，省略通知正文 | 观众见过信封 | 观众与小说读者已经知道相同内容 |
| 第六场祁说“听梅讲，铺子要换人” | 祁听过这项说法，还说给在场者听 | 铺面已实际交接 |

若将第六场移到第四场前，先检查“听梅讲”的时机是否已有来源，再看后续哪次转述或决策依赖它。修法可以是保留原顺序，也可以在授权范围内给原已存在的传递动作换位置。若必须虚构一次会谈才能成立，标明这是新的创作选择。

## 回写的一次完整操作

- 待定稿标成提案，并留采用它的稿名。将来可能出现的动作留在计划层。
- 作者确认作品版本且任务包括维护正式记录时，从认可段落取出持久变化。记录原状态、更新内容、有效时点、事实或传言属性、依据位置和受影响的去处。只涉及当前段落的生活动作通常随正文保存即可。
- 写入前重读目标记录和其对应的现行正文。若期间出现较新版本，先对照同一事实；条件仍相容时只补差量，已存在同一证据时结束。发现授权、人物身份或重大结果在两份权威依据间互斥，保留冲突并指出需作者定的一点。
- 写入后从正文追到条目，再从条目返回正文，复查真正使用该事实的下一处。小说和改编剧本各记在自己的版本；跨载体的共用设定需有明确的采用依据。

若主记录已写成，派生摘要更新到一半，重试时先读现行主记录及遗漏项，只补未完成的摘要。正文与台账难以对上时保留最后一次有据的状态，把未经核实的变化单列。修订早章要把变化推到最新已写切点，仍然有效的后续经历继续保留。

## 三种容易误报的情况

同场被谈起的人、电话里的声音与亲自在场的人，其行动和知情权限分别判断。物件遗失以后又出现在场内，分辨角色在回忆、拿到副本还是确实重新取得。在两条并行叙事或可选分支里，分别检查每条实际走到这里的路径；汇合场只能默认沿各路都已获得的条件行动。查旅行时间时使用故事已给出的最宽容时间范围与实际可用路线。若只写“早上”且多种走法都可能，列出不确定性；只有所有合理走法都赶不到才判为硬伤。
````

## 3. 长篇、多线与连续性

资料库路径 `SKILL/laotang-storycraft-zh__老唐创作套件/references/continuity.md`。范围为原文件第 1–52 行。

````markdown
# 长篇、多线与连续性

章节、群像、剧集、系列续写和前后依赖修改时读取。短故事不必建立完整资料系统，优先沿用用户已有记录。

## 长度来自后果的积累

掌握主导关切、已定节点和收束方向，再写当前完整单元。不必穷尽全书每场，但可试推后续几个单元，看是否从人物、关系与规则中持续长出不同过程。不断换麻烦名字、延期误会或重置资源，不能证明容量足够。

阶段给实际回报：获得什么、失去什么、理解如何变化、新义务怎样形成。结尾可留下后果和选择，不必永远悬崖。支线通过信息、资源、关系或选择影响主线，或提供不可替代的体验；不要求每条都在结尾机械会师。

区分主角、视角人物、情感关注对象和当前推动者。暂时被动不等于不是主角，配角也不必人人配全套弧光。已确认的整体安排帮助定位，不压过本轮实际材料。

## 几种记录不能混为一谈

| 记录 | 要记什么 | 不能冒充什么 |
|---|---|---|
| 已确认设定 | 用户定案的规则、人物、事件及依据 | 未选方案不能当事实 |
| 已呈现信息 | 定稿真实写过的内容和位置 | 大纲计划不能当已铺垫 |
| 人物知情 | 谁何时经何渠道得知、误信或怀疑 | 作者知道不能变成人人知道 |
| 可用条件 | 资源、物件、资格、伤势、欠情和承诺 | 计划取得不能提前到账 |
| 读者等待 | 已建立的关切、线索与当前兑现状态 | 所有细节都不是回收义务 |

这些维度可以交叉，一项规则可以已确认但未呈现，一段台词可以已呈现但内容虚假。信息来源、可靠程度与状态应一起看。钱粮、路程、通信、权限、物件归属和身体状态按实际需要追踪，已消耗的条件不能无解释恢复。

必要记录可用条目、内容及依据位置、关联位置、本轮变化。标识只有跨章引用需要时才加，不生成空白大表。摘要帮助定位，关键事实仍回原文，不假称“上章已铺垫”。缺关键上下文就说明限制。

## 多线按两种顺序读

先单线看目标、动机、时间和结果，再按实际交错顺序看定向、记忆负担、重复信息与情绪延续。单线顺不等于任意剪接都顺。某线久未出现后要让人重新接上关切，不靠大段复述拖慢其他线。

线索复杂、自己也理不清时，可以画一张结构示意或列一张时间表，只为看清，不是每个故事的交付物，用户要正文就不先交它。画的时候分开几样：故事里实际发生的时间，呈现给读者的顺序，同时进行的并行线，以及人物考虑过却没有选的做法。同时发生的事不能画成主角没选的另一条路，没选的做法也不能当作已经发生。线数没有定额，单线、双主角、并列群像都可以。

交汇来自共同条件与既有行动。区分同日发生和同时呈现，区分读者已知与当前角色已知。前传不引用后来才得到的信息，续作明确继承的关系、伤势、承诺和公开事实。

## 修改沿依赖传播

先标本轮改动及原依据，再定位受影响的前置和后续：动机、知情渠道、资源、时间、伏笔、结尾是否依赖它。已授权范围同步，越界部分只明确指出待衔接位置，不悄悄重写全书。

梗概、人物表、分集、译文和其他衍生稿仍沿用旧内容时要说明，不能让它们默默对不上。未写计划可以修订，已经发生的后果不能靠改计划注销。记录只服务写作，不主动建立私人档案或全自动资料库。

## 把连续性当成状态变化

长篇检查不只记“发生过什么”，还要记每次关键变化前后的状态：人物在哪里、身体能做什么、手里有什么、欠谁什么、知道什么、相信什么、正在赶什么时间。只追踪会影响后文的状态；普通生活不必全部入账。

对每个重要伏笔、承诺、疑问和线索，区分计划中的、已经写出的、正在兑现的和已经改变用途的。设置先于回收，人物知情先于据此行动，资源取得先于使用。若顺序有意打乱，给读者足够的叙述依据，不把“作者计划”当作正文已经存在。

## 修改前先看连锁影响

移动或删除一个场景前，先列出它建立了什么：人物第一次知道的事实、物件的归属、关系的承诺、时间的压力、读者的等待。再判断改动会提前、延后、取消还是重新解释这些内容。需要时在草稿副本上试排，确认没有把线索提前回收、让已死人物再次行动或让人物使用尚未取得的条件。

多线并进时分别按故事时间和呈现顺序读一遍。交错不是把两条线轮流摆放；每次切换都要让读者保住当前关切，并在回到旧线时知道新增了什么压力。一个人物考虑过的方案、作者删掉的段落和故事里实际发生的事件分开记录。
````
