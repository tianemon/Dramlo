````markdown
# 看片定位与返修

记下受审文件、剪辑版本和时间基准。能播放的片段先带声音按正常速度看一遍，再回到第一次误读处逐段确认画面、声音、字幕和前后切点。只有静帧、无声片或转录时，分别说明能判断什么；外部人员提供的时间点记为对方反馈，亲自核看后再写实见结论。用帧编号时注明帧率。

单项意见写明“版本、起止时码、可复现的现象、哪个观众判断受到影响、改在哪里、怎样复看”。例如某剪辑版 00:21–00:23，柜员尚未移开信封，芸已盯着空柜面答“明天几点”。核对前后镜头和可用素材后作以下分派。

| 能观察到的情况 | 返修与复看 |
| --- | --- |
| 原始素材包含柜员取信及芸移开目光，两段可按正确次序衔接 | **剪辑可修。** 改入点、出点或画声衔接，必要时延长识读时间。重看这一处连同前后动作、语气、房间底噪及字幕停留 |
| 原剧本、分镜均已要求露出收件人，现有素材中姓名糊成一团，且找不到可辨的替代段 | **补拍或重出素材。** 说明缺失的信息与可用范围，保持道具状态、动作方位、说话时间及衔接帧一致。新镜回到同版时间线复看 |
| 所有画面都忠实实现分镜，但分镜漏掉剧本已经建立的收件人线索，或剧本就没让芸接触足以辨认的证据 | **上游返修。** 并列剧本、分镜与实片位置，找出首次丢失依据的阶段，只改该阶段及其依赖。重新核对观众何时知道、谁能据此行动 |

若只有导出片而无法看待选素材，“剪辑可修”先写成有条件的判断，并指出还需哪段余量或声音。若证据支持多个独立问题，可分单开列。涉及节奏与审美时说明想让观众感受怎样改变；客观缺漏和口味取舍分别定性。复审引用新版同一动作或对白及更新后时码，保留已解决、仍存在、无法验证三种结论。
````

## 2. 一轮适用质检

资料库路径 `SKILL/laotang-cinematic-storyboard-s10-free__老唐创作套件/references/quality-checklist.md`。范围为原文件第 1–62 行。

````markdown
# 一轮适用质检

只查当前任务；不重走全部创作流程，不读回归用例库。发现问题修最小范围及受影响时间/接续；报告只写用户需要的结论。纯提取不补导演，时间总览预览不按完整字段验收。

## A 范围与授权
- 新故事首轮仅确认卡，六项都列（三档粗估最长不超过15秒免分段；分段项推荐每份最长30秒、另列15秒）；明确免确认才直接做。“直接完整版/其余你定”不当免确认。已确认的同任务变更/返修不重复问。
- 确认状态与六种参数来源可回查；完整版回执按gate，预览不展示。未知/冲突只问影响项；素材缺失不阻塞文字准备稿。
- 当前阶段正确，确认/继续不越权；翻译、改词、改锁定拍法有授权。完整稿返修仍完整，当前范围交齐，不漏后半段；分批标范围且镜号/时钟不重置。
- 前置风格一级选项中的写实与CG各为独立项，工具、卡片、总推荐、复制块一致；未明确直出时先预览位于第一项并实际预填，不拿旧对话替代本轮选择。当前明确直出或已认可骨架要求细化时仍执行原授权。

## B 故事与人物
- 必要事件、采用对白、声源、结局都有承载；动作不重演，未新增秘密、习惯、履历、伤势、道具或人声。预览画面重点已逐字写全采用台词，完整版仍从原稿复核。
- 人物和观众知情正确，反应按最终语言信息到达；画外声不串听者口型。揭示窗口按全片T映射，改T后同步。
- 完整稿关键表演具体：起态、触发、主变化/幅度、回应、余势可查；可从行动反查向谁争取什么、何种反馈改变做法。静默者也有适用倾听，反打不复位，后半不退化成情绪标签；不单凭表情读心。
- 景别/裁切/受光/遮挡/焦点/停留能看清证据。脸不可读改身体通道；双手任务、口型、支撑受力、步态兼容，反馈有实际感知；主反应少而明确，辅助动作不过载。
- 每个新建/细化镜可反查主体、起态、动作/依赖/关键接触、尾态、机位构图、声源；不适用不填。普通交流不强造冲突、固定微动或策略数量。

## C 摄影与空间
- 镜头有观察职责；短句/转眼/换手/状态格不自动切镜；固定长镜可靠连续表演推进。构图层级、裁切、留白、进出空间成立。
- 人物在场/画外/离场、世界位置与画面投影清楚，转身不当换位。机位挂地标/方向/背景，空镜插入POV不编地标；隐藏或裁出地标写画外效果。
- 适用完整蓝图时可仅凭布局+镜头盲画机位和人物侧；机位与主光按世界关系推导。正反打视线相反且高度匹配，过肩点名哪侧肩，背景/单人留白正确；越轴有合法过渡或用户锁定直切所需三条件。
- 不变世界布局沿用；人物真实走位后当前起态更新，不逐字复用旧锚位。每份输入自足，无“同上”；反默认写正面几何，背影/远景身份标签有依据，关键持物手不偷换。
- 回头/躺卧/身体和头朝向合乎身体；镜头旁目光不直视镜头；机位旁人物入画与否明确。物件归属、抓握、伤势、光线、声音、动作阶段沿实际保留边界接续。
- 主体运动与相机运动分开；运镜有起幅、触发、路径、速度倾向、落幅或运动中切出；固定不暗含推摇。运动不遮掉关键表演、接触或证据。
- 跨生成大段：按实际保留首尾核观看选择与接续；同构有持续表演/观察依据即可，换景别按信息尺度，不设阶梯或强制变化。不丢因果、揭示、轴线与关键表演。内部核完整状态，完整版只给必要对照，预览体现实际镜头结果；未看媒体不称无缝通过。

## D 时间与分段
- 采用语言、完整词句、自然读法、动作依赖与可读窗口估时，真实并行才取并集，不能预演句末信息。必要评估不机械封顶0.3秒；已有并行不另加话后秒数。
- 清除机械话后反应、无职责起势/拖尾、重复建立状态、等相机停稳、统一语速、填段等注水；不裁掉必要等待/情绪余韵。硬切0秒，常规过程可省，不靠快切/快读缩短真实事件。
- 对白为主且S>0核R；动作/环境为主不算R，核全片唯一事件轴。S含原有非语言人声，多声源重叠时T−S不是独占非台词时间。计划/估计范围/录音或媒体实测分开。
- 顺序是剧情→全片自然长度→在剧情断点分段→段内分镜→用实际镜长复核。每段长度等于该段剧情自然占用；没有为接近U而拉长镜头、加停顿、空镜、慢放、重复反应或新动作；段界落在剧情断点，没有劈开一句话、一次交流或一条动作链；段内镜数按剧情定，不按配额。
- 固定总长冲突不偷改任何硬项，正余量不自动停顿。先定T后分段，U只约束输入；最少可行K下在合法切点均衡，整体可行先于局部最近，过短段回查，不改镜长/顺序/事件。不因某段未满填秒。
- 三档粗估/自然口径有内容职责，台词自然速度不随档位改；标准/舒缓增量可定位。固定总长三档只改分配不要求三个总T递增；与粗估显著偏离先审计，不追倍率凑长。卡片三档已过演一遍复核：紧凑动作节点平均不超过约1.3秒（超出能指名原文写明的慢、停留或揭示节点），边做边说的台词没有和动作串行相加；正式总长不超过所选档粗估约一成，超出已查重复计时。
- 每镜终−始、全局/局部映射、编号与合计正确；T/D按保留区间并集，L逐份核U及已知V，另给U_D才核D；未知参数不编。取整/叠化/并屏/余量不偷减真实素材。
- 锚点默认关；开时完整有效1秒、全静止静音、只计实际成片保留，按段数/方案重算，不挤剧情；文本续批不加锚点。段内镜号递增、新大段归一，独立输入时间归零。

## E 素材、声音与完整稿
- 按full-output共同字段/顺序与选定模式；完整头模块（【参考职责】除用户明确纯文字的无参考稿外都有，未提供素材时为默认准备稿槽位、【全局光影画风】、【场景布局】启用时、【注意事项】、【角色声音】适用时）齐全；每镜空间、动态、音频、尾帧齐全，可选栏不凑空栏，不留占位或省略号。参考/风格/布局/声线按每份输入自足。执行块内没有A位/B位等块外机位代号或“见空间示意”，机位都写成地标描述。
- 连续剪辑前尾后起相容：动作相位、世界位置、持物/接触和持续伤势等不无故复位或重演；情绪可随真实时间自然收势。明确时间省略、平行剪辑和换场按其关系更新。内部全量状态可回查，正文必要状态清楚，不要求固定“下一镜第0秒保持”句式或逐镜重复清单。
- 关键变化节拍有足够信息触发、可见行为与必要反馈；稳定倾听、等待、保持也是有效表演，不要求每镜新变化。衣发/装备惯性仅在实际存在且可读时使用；不复制无依据小动作，不禁止剧情需要的持续/重复行为。
- 文件提供、映射与入口绑定各有证据；准备稿不冒称可投喂。参考继承/隔离按真实素材与已定职责，不套棚拍/静音假设，不排斥有依据的同构或指定首帧；有图不堆静态外貌。母版、派生态与生效事件正确，无相反状态竞争。
- 世界布局、有几何依据的背景互斥、当前构图、外观/风格/真实首帧职责分清；裁外不脑补，示意色码不成为服装/字幕，排序与文字锁定不冒称实际生效；局部编辑允许合理阴影/反射/受力联动。
- 所有实际发声者（含画外/设备）有归属；稳定声线与句旁表演分层。有主音频不对抗、未听不假称已对齐；无音频写本次可区分设计，至少含音高、质地、共鸣或气息、吐字节奏和一项角色特征，同场至少两项可区分，不裁既有详细设定，不推断年龄/身份/口音。静默者不加声源。
- 对白原词完整；外语执行块只发声原句，中文释义在块外逐句对应。读法在台词前、引号外不复述原词；声音窗口、远近/空间、适用的Audio Ducking退让层次及实际跨镜接点与画面相符，背景不盖关键对白。
- 默认无硬字幕/水印/BGM及器乐，原剧情文字另判；用户覆写同步删互斥项。纯空镜不强填角色声线，无对白不等于绝对静音。

## F 预览与验证
- 只有标题、镜数/预计总长、四列表；画面重点按“景别/机位/运镜＋人物动作（含关键反应/状态）＋完整逐字原话＋必要声音”写全，兼顾丰富度与审阅可读性，不压成一句大概。无逐行三标签、回执、估时计算、段界五行、空间图、表演附录；折叠区/JSON/复制也不藏它们。必要冲突或合成计时最多短注说明。
- 预览交付后，聊天最后单独一段原样附固定提醒（见[preview](preview.md)“预览后的固定提醒”），网页顶部有同句提示条；提醒不进四列表、notes、复制内容和下载MD；除这句外没有别的确认话术。直接完整版不附这句。
- 忠实提取保号、保镜、保时，缺项写未说明，不补拍法/表情/译文；原稿已有的动作和对白照实写全。画面重点不成为改原台词的授权，完整版重新对原稿。
- HTML、复制、下载MD同一公开文本；仅手动原文区可折叠。按钮成功才报已复制，失败给可选择原文。检查浏览器实测范围，没跑就不宣称点击或显示通过。
- 只改用户点名与真实受影响项。没有媒体不作效果结论；单帧不能证明运动，波形不能证明音色，不能裁掉唯一接触/原对白/揭示证据就称通过。文本/算术与媒体效果分开。

## G 角色表演专项（预览与完整稿都并入同一轮，不另开检查）

- 加载覆盖人、动物、机器人和拟人物品；自然动物未被擅自拟人，普通静物和背景动物未被赋予意图；器官、肢体、关节、材质与造型一致。
- 关键节拍的实际正文有具体动作/神态前后差别、足够信息触发和注意对象，不只写“神情复杂、表演自然”；脸不可读有可见通道，稳定保持不被强加微动作。
- 表演细化没有增加镜数或延长已排镜长：没有为展示表演加“停顿片刻”“片刻后才答”、延迟回应、慢放、额外反应镜或特写；能与话尾或已有动作并行的反应已并行。与只按剧情排镜相比，全片T没有因表演变长。
- 镜内多节拍在镜长内、与最终词序相容，没把节拍等同切镜；克制、直接爆发、喜剧和自然收势按原故事。原文笑声、不完整句和打断照原样保留，说话者也写了当前注视和状态。
- 非人发声按实际口部或设定声源，没新增嘴、人声、动物叫声或机械表达声；必要拟音另判。

测试维护另见 `tests/regression.md`；创作交付不加载该文件，也不为查一个问题运行全套用例。
````

````markdown
# 提交前与出片后质检

## 提交前

1. 文本盲读：只看最终 prompt 和真附件，能答出画里几人、谁站哪、看谁、手里有何物、本镜何时让状态变化、停在哪吗？不是所有场景都需要手部特写，但重要的手和道具不能省略。只有“有氛围、很紧张、电影感”判失败。
2. 原文核对：未改剧本事实、人物与人数、时空、对白和动作结果。参考地址仅属制作记录；当作模型可见时，须核实实际绑定的文件、顺序、模式和参考用途。相互矛盾的硬约束不得提交。
3. 查缩水链路：比较镜头稿、节点存储值、上游文本节点合并值和实际请求体；区分展示截断与请求截断。有自动改写则记录前后版本，不擅自重复改写。不要输出密钥、认证头或无关日志。
4. 核对模式与尺寸：首/尾参考槽、画幅、宽高实际值、时长/FPS 和参考文件。9:16 成片不能直接把 16:9 画面非等比拉伸；如果只有横屏可用方案，明确重构/裁切/留边取舍，再由用户决定。
5. 安全拒绝就停止该镜自动重试，如实保留原剧情和拒绝记录，必要时报告厂商与请求 ID。不得为了继续生成而把孩子变包袱、隐去关键事实或反复试探过滤；用户同意才变更内容表达。

## 出片后

- 关键帧抽查：起点、中间、结尾。检人脸/人数、衣着饰物、自身左右、目线、手与道具、场景地理、运镜到点、比例；要验证全段动作与音频就播放，不把三帧抽检说成全段已审。
- 两镜并放：上末帧与下首帧的状态是否吻合，是否重复、瞬移、换手、越轴、变形。看完整片段确定是运动问题还是构图问题；听对白与底噪，别把“有音轨”当成“对白和配乐正确”。
- 结果分为通过／需修／无法核验。记录镜号、实际版本、问题证据、本轮只修什么、不变约束、是否需要重做。先排查参数/连线，再改 prompt。保留已通过的资产和镜头；不刷新整条链路。执行状态未知先核对队列与结果，避免重复扣费或重复生成。

[回归样例](references/regression-cases.md) 用来测试新 Skill 或改写器，不必真调用生成服务。
````

## 4. 回归测试

````markdown
# 回归测试

| 输入 | 通过标准 |
|---|---|
| 乔装同一角色，两张图一张人脸一张服装 | prompt 给每图唯一职责；未继承服装图的人脸/姿势 |
| 骑士与孩子双人镜头 | 恰好两人，姿态和视线可定位，斗篷状态明确，不得替换角色 |
| 上一镜已经披上斗篷 | 下镜从已经披着切入，不再动作重演 |
| 已有上一镜真实尾帧，生成下一段 | 图绑首帧，不绑当前尾帧；无额外参考混用到只收一图的 I2VA |
| 两张竖幅端点相距太远且光向矛盾 | 不直接承诺能过渡；提出重做同机位端点或剪辑 |

| 画面和声音要接续，模型每段都自配乐 | 保环境/对白，配乐另做场次轨，交代具体切点 |
````
