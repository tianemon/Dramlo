````markdown
description: 将剧本、故事或导演方案编成分镜时间总览、逐镜制作表或可单独复制的镜头描述，核算镜长、剪辑接点和生成段容量。也可忠实提取已有镜表、调整指定镜头或核查跨段连续性。

# 分镜与镜头表

先辨交付物。新建分镜可决定观察对象、机位和切点。整理旧稿按原编号、顺序和已知时间搬录，未知写“原稿未说明”。已有骨架获准细化，沿用真实原稿复核台词与结尾。指定要完整表就直接交完整表。只改某镜，追踪真正受影响的起止时间、声桥和下一镜起态。作者已有模板优先。

## 排镜

1. 摘出给定时空和在场者，给每项必见事件、定稿对白、声源、允许揭示时刻与结尾找到承载处。区分作者锁定的事实与本次拍法设计。未经授权，保留原话、说者和语序。翻译获准后按最终发声稿重新计时。
2. 先估全片自然占用。明确是成片固定总长、单份上限还是大致目标。有分份要求时，先在完成一次交流、操作、场次转换等位置初分，再进各段按观看职责定镜。每份含多镜与每镜独立交付分别处理。普通镜头表不必凭空制造生成段。
3. 推演每镜起幅、观众要读的证据、人物与摄影机各自的运动、声画关系、结束状态。动作格、台词行和运镜内部阶段均可处于同一镜头。有意保持的长镜允许持续。涉及多人、非人表演、交接或越轴，读[镜头设计与接续](references/shot-continuity.md)。
4. 用实际镜长复核全片和每份输入。遇到并屏、叠化、余量、锚点、固定总长或段长限制，读[时长、剪辑与容量](references/timeline.md)。目标入口未经核实就交通用文字方案，具体参数标计划或待核。

## 交付形态

- 供审阅时采用[四列预览](references/assets/overview.md)。各镜给完整原话及必要动作、机位和声音。多人或多段用稳定编号，未知全局位置不能自行补成从零开始。
- 供摄制或剪辑时用[逐镜制作表](references/assets/shot-list.md)。逐镜串读能完成整场，稳定造型、地标和主光可以在场头共用。生成分段或单镜单投再用[独立输入页](references/assets/input.md)，重写该输入所需上下文。制片阶段的细则及局改见[交付与返修](references/handoff.md)。

交前从最后一镜倒查结尾和揭示，再顺着原稿核一遍关键动作完成次数、原话、镜号、镜长、声源及接缝。说明文字排期、已有录音计时或成片实测的依据。一张分镜表可完成文字设计，实际唇形、声画同步和生成结果须看片或听声才能确认。
````

## 2. 交付与返修

````markdown
# 交付与返修

## 选对读者所需的稿

预览面向需要决定镜头和时长的人。每行先写观看位置，再写有职责的动作、实际承担的原句及声源。长对白保留，不借“预览”自行概括。用户若指定摘要，只摘要获准部分，并保留正式版采用的定稿依据。需要可复制的网页时，页面、复制结果和导出的 Markdown 共用同一份公开表格数据，核对长对白、换行、特殊字符和下载结果。无法验证浏览器时如实说明。普通文字委托可以直接交表。

逐镜制作表面向演员、摄影、录音和剪辑。场头统列适用的画幅、主光、角色当前状态与空间。逐镜写发生变化的部分。原稿忠实提取保留既有镜号及局部时间属性。原稿只有“镜 7，3 秒”时，不得据此写全片 0—3 秒、虚定机位或补一个固定镜头。审校结果定位到具体镜，不擅自重排其他场。

独立生成输入按一段多镜或每镜一份组织，块外记该份编号、在成片的全局位置和剪取口径，块内从零排局部时间。每份重写有效的地点、人物、持物、动作起态、画幅与必要声场，不能只写“同上”。原稿里的情节、模板里的示例、上一张素材里不相干的背景与新输入隔离。

参考准备需分别记下文件是否提供及读得到、标签与角色或状态是否映射清楚、入口是否实际绑定。角色图可负责身份，布局只取世界几何，特定首帧才继承起幅，音色样本不带走异文和混响。没有素材时先按用户要求给文字稿或说明待提供的对象。未绑定标签不得称已生效。执行块里只留本次要交给执行方的内容。改入口时复核该入口如何接受参考、时长、镜序、画幅及口型，未知保留为通用计划。

## 从症状找到应改的那一镜

| 观察到的问题 | 检查与修改 |
| --- | --- |
| 一句长台词跨镜后复读或被吞 | 连起来与原发声稿逐字对照，把重叠或缺失定位到切点，再按实际分担重写 |
| 手持关系与动作方向跳变 | 从实际保留的上一镜末列持有人、手别、接触状态和下一项动作。仅修改相抵触的镜或接点 |
| 重心平移却不走路 | 保住原有支撑或抓握，释放腿部完成已有步态。不必让全身定格 |
| 返修“表情太早”意外改动时长和声线 | 定位足够获知的字词，改当时能看见的反应。复核必要阅读窗口和下一镜起态 |
| 主体和场景随参考漂移 | 拆解素材实际负责的维度和生效时刻。只有已读到的参考才可判断污染来源 |
| 同构续段似乎顿了一下 | 比较实际剪点两边的姿态、速度、运动方向及声音。只看尾图时保留动态待核 |

## 一镜可读的例子

原稿是“何把信封递到钱手里。何说‘先别拆’，钱握住信封，抬眼看她。”用固定双人中景让两人的脸和递接双手都留在画幅内。钱先看交接点，握稳以后再抬眼。何的声音即便在手部成为观察中心时也仍来自何。全镜只完成一次接物，不补拆封、惊讶或另一句回答。若用户只要读旧镜表且从未指定景别，上述固定中景只能作为另行委托的拍法设计。
````
