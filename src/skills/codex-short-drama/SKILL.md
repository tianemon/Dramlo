# Dramlo 短剧创作

先确认本次要交付的范围和项目内已定稿的版本。按当前工序读取对应手册。外部 Agent 通过 Dramlo 技能库按 ID 取正文；配置、工具参数、任务状态和操作权限以当前 MCP 指南为准。

| 创作任务 | 手册 ID | 完成标志 |
| --- | --- | --- |
| 写作、改编或修订一场戏 | [ai-short-film-screenwriter](ai-short-film-screenwriter.md) | 行动有动机，转折有依据，保留采用的对白和揭晓顺序 |
| 把剧本拆成可剪辑的镜头 | [storyboard-director](storyboard-director.md) | 每镜写清观众获得的信息、动作起落、声音与切点 |
| 建立可复用的视觉依据 | [character-consistency](character-consistency.md) | 角色、场景及道具的稳定特征和分场变化可追溯 |
| 预演复杂构图与调度 | [storyboard-panel](storyboard-panel.md) | 按顺序读图能辨清空间、动作阶段与接点 |
| 写生图正文、准备单幅首尾帧 | [shot-image](shot-image.md) | 每幅对应明确时刻，参考图与所需用途一致 |

## 项目内如何衔接

1. 先按剧本顺序搭分镜、资产卡和依赖。上游尚未产出时也可以写下一镜的初态、所需参考和采用条件。普通切镜可独立构图，同机位连续动作可依赖上一镜采用版的真实接点。
2. 分别保存分镜叙述、生图正文和视频终稿，对应镜头的 `visualPrompt`、`imagePrompt`、`compiledVideoPrompt`。局改时复核哪些下游内容依赖已改事实。要长期采用的文字写回项目。
3. 先用已有素材或静帧检查整场节奏，再选最需要验证的镜头做样片。准备稿写明目标、素材用途、实际工作流和验收条件。只有准备委托时交到这里。
4. 按用户批准的范围串行生成，每步归档后核对绑定。下游依赖采用版时，等选片明确再继续。失败或结果未知先查已有任务，恢复从首个未完成项继续。

遇到执行疑问时，先确定要向 MCP 核对的事实。输入被拒时，查本镜选用工作流的槽位契约以及实际传入的素材。生成成功后画面仍是旧版时，依次读回本次产物、镜头采用版和时间线引用，定位差异后再决定是否换选。这两种检查都可在重新生成前完成。
