# 人物、场景与道具参考

先读取已采用的角色、场景、道具卡及其版本。为每个对象区分跨镜稳定的特征、本场允许改变的状态、变化从哪一镜生效。缺图时可以先建卡并指定所需参考，待素材到齐再验收。

## 设计参考资产

- **角色。** 身份以已采用的形象为准，服饰与身体状态按当前场次取用。需要标准四视图时，用同一媒介、均匀光、纯白背景，依次给出面部特写、全身正面、侧面和背面，保留比例与造型。短暂的姿态和表情留在镜头稿。
- **场景。** 固定物理布局、出入口、地标、活动范围、时段、表面材质和光源位置。反拍时从新机位推算画内左右、遮挡和受光侧。地点设计板可分格展示全貌、主锚、站位区和光源；约束单个构图时提供相应角度的单幅。
- **道具。** 锁定足以辨认的形状、尺度、材质、朝向与关键部件，需要时补多视角。按镜记录位置、持有者、使用状态和变更时点。

交付时标明每份素材的 ID、采用版本和约束用途。逐镜核对真正入画的对象，区分可见、画外和仅被提及的人物。工作流缺少参考槽时，明确哪些特征只能由文字引导，选片时单独复核。
