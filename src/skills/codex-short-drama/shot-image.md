# 生图正文与单幅端点

确定图片承担的用途后再选时刻。首帧应给即将发生的动作留下空间与可行的初态；尾帧应表现预计剪出时已经达到的状态。分镜配图可以记录一个瞬间，也可按项目版式分格检查多个拍点。

## 写可直接生图的正文

1. 从机位能看到的内容落笔。依次确定景别、视点、画面主体、空间关系与焦点。以固定地标或清晰边界说明前后、距离和遮挡。
2. 在一个瞬间内写清姿态、视线、持物和接触关系。若正文需要连续几个动词才能成立，选取其中决定起幅或落幅的一刻，其余动作交给视频稿。保留后续运动所需的活动范围。
3. 写入影响辨识的环境、材质、主光方向、时段和媒介。已由参考图锁定的造型，只补充本镜可见的状态变化。按素材归属核对实际参考，纯文生图路线需在成图后复核身份一致性。
4. 版式、画幅、标题和制作说明放在对应配置。多格正文仅按方位描述各格的可见内容。剧情要求画面出现文字时，写明载体、位置与定稿原文；其余画面保持无标注。

交稿时把制作说明收起，只读生图正文和实际附件：能否据此画出一幅确定的画面？如果能画出两个不同的动作阶段，选定其中一个；如果人物间的前后、视线或接触关系有两种读法，补一句位置关系。首帧还要核对下一步动作是否有空间发生。

## 选择端点素材

单幅首尾帧应能独立成立。使用看板中的某一格时，先核对动作阶段，再实际裁出单幅，检查格线、主体完整性、分辨率与目标画幅。没有合适格时单独设计端点。交付生图正文、版式与参考用途，采用时复核生成文件实际内容。
