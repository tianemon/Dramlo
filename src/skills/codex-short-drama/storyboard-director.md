# 分镜脚本与剪点

以已确认的剧本为来源，按场次写可编辑的制作稿。先用一句话说明本场结束时观众多知道了什么、对谁的判断发生了什么变化。再决定何时让观众看见证据、听见线索或停留在反应上。

## 逐镜设计

| 镜头卡 | 写作要求 |
| --- | --- |
| 镜号、场次、时长 | 沿用稳定镜号，单列播放顺序和预计剪辑长度。生成时长需要留裁切余量时另记。 |
| 叙事任务 | 写出这一镜独有的信息或情绪变化，以及观众从画面的哪个位置或哪个声音读到它。 |
| 起态、触发与落态 | 记录在场者、画内位置、朝向、视线、持物和接触关系。写清变化由何引发，切出时已经完成到哪一步。 |
| 景别、机位与运动 | 先定必须看清的范围，再决定景别。注明相机在哪一侧、朝向哪里、谁可能遮挡谁。需要运镜时，写触发、路径、焦点和落幅。 |
| 对白与声音 | 标明发声人、原词、听者及反应入点。环境声、动作声和跨镜声桥分别指定来源与起止。 |
| 素材与接点 | 标明身份、地点、道具、看板或端点各自的来源。写明下镜继承的动作阶段、视线或声音。 |

## 决定在哪里切

- 观众已读完当前变化，或接下来需要新的观察位置时再切。在动作中切换视角，前镜负责起势，后镜承接同一阶段的运动方向和速度。刻意跳过时间时，留下足以识别省略的线索。
- 对话反打按人物之间的轴线推算目光方向和高低。跨轴时用可见走位、移动机位或重新建立空间的画面帮助定位。同一处灯光、出入口和地标按新机位重新投影到画面。
- 同机位无缝续拍取采用版接点处的实际帧。换机位可以新构图，匹配动作、持物与方向。换场根据叙事意图重新建立空间。
- 按目标画幅试排遮挡和留白。竖屏多人场面可通过纵深、分层或反打交代关系。只有能看见关键接触、读到屏显、听完整句，估计时长才成立。

交稿前静音顺读画面，再单独读声音，最后按预计时长连读。逐镜问删掉这一镜会损失哪项信息。对于局部修订，核对两侧接点与实际依赖后决定修改范围。
