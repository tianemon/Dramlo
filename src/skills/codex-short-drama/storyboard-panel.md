# 故事看板

需要验证站位、遮挡、走位或动作接续时，按已定分镜制作看板。素材未到齐时可先用轮廓排机位。只需确认一个构图时，用单幅即可。

选取能区分动作阶段的时刻。每一格表现该时刻已经成立的状态，按阅读顺序能看出变化由谁触发、何时接触、谁接手以及最后停在哪里。停顿承担反应或新信息时才单独占格。

按项目选用的版式安排格数与阅读顺序。普通六格线稿用 3×2，电影章节使用彩色看板，单一动作排 2×2，多阶段动作或蒙太奇可排 4×2，从左到右逐行阅读。用剧本的年代、地域和天气核对跨格服装、陈设和光线。跨格核对主光、方向、视线、可见人物、道具数量和所有权；有意换机位时保留空间参照。

提交视频前说明看板约束走位、机位还是节奏。需要精确端点时提供独立单幅，并核对裁取或重画后的构图、动作阶段与尺寸。
