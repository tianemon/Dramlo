# 选片、粗剪与交付验收

按委托确定检查到哪一层。只有剧本时判断叙事和可拍性；已有分镜时检查信息顺序与接点；有原片和音轨时再判断表演、速度与声画同步。

1. **计划。** 核对镜头顺序、预计时长、可见角色、参考用途与必需输入。上游已经指定但尚未产出时标为等待；缺少来源或工作流能力时指出具体镜头和输入。
2. **选片。** 对照候选版本、镜头当前采用的素材及时间线实际引用的文件、入点和出点。重新选片时找出引用旧图或旧接点的下游镜头。
3. **看片。** 原速带声连放相邻镜头，再分别静音看方向、动作阶段、持物与视线，只听声音检查台词、声源和跨切连续性。逐帧定位接触或口型误差。只有静帧时，将判断限于可见的构图与姿态。
4. **修订。** 区分剪点、接线、源素材和表演问题。先判断现有素材能否通过裁切、换选或声桥满足意图。需要新拍点时只补受影响的镜头，并复验前后接点。
5. **成片。** 看实际导出文件，核对尺寸、帧率、时长、音轨、字幕原词、可读时间及边缘遮挡。需要干净版、独立配乐或音轨交付时核对可用源素材与交付规格。

验收记录给出镜号、采用版本、片内时间、观察到的现象和最小修订范围。推测单列，注明可验证的条件。生成被拒时按服务返回的原因记录；涉及改变既定剧情、角色或关键对白时，由作者决定。
