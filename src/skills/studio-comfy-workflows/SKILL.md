# ComfyUI 工作流发现与接入

## 导入 Dramlo

沿用 Dramlo MCP，用 `studio_get_guide` 读 `comfyui` 章节，按当前连接的 `tools/list` 查看发现、读取和导入工具的参数。

## 为其他工作台取得 API 图

已有独立 ComfyUI 发现 MCP 时，从该连接的 `tools/list` 查读取工作流和导出 API 图的工具。交付 API 图时附上核实过的输入槽、时长单位和成品输出。
